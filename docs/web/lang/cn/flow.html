1. 服务流程

1

搜索

粘贴 1688 链接，查看分析报告

2

联系

WhatsApp 告诉我们款式、颜色、数量

3

下单验货

付款 → 1688 下单 → 货到仓库 → 验货拍照发你

4

确认发货

你确认 → 付国际运费 → 打包发货 → 给运单号

5

收货

5-12 工作日到货，有问题 WhatsApp 找我们

2. 付款

1

第一次付款 · 下单前

商品费 + 国内运费 + 固定服务费。付款前给你完整明细，没有隐藏费用。

2

第二次付款 · 验货后

国际运费，按实际重量/体积算。验货确认后再付，不确认不付。支持 Wise · 银行转账 · 本地电子钱包。

服务费不退。因工厂缺货/不发货导致无法采购，商品费全额退还，服务费不退。

3. 验货

到仓 1 天内拍照发 WhatsApp。请 2 天内回复确认（1688 退货窗口仅 7 天）。2 天未回复会再催一次，仍未回复默认确认通过。免费仓储 30 天，可申请延期。

✓

款式核对

是不是你选的那个款、型号

✓

颜色比对

实物和 1688 图对比，明显色差主动告知

✓

数量清点

件数、配件、赠品对不对

✓

外观破损

有没有裂痕、刮痕、变形、污渍

✓

质感差异

材质、做工和描述是否明显不符

不验：电子功能、材质真伪、品牌授权。如需量尺寸/称重/通电测试，下单时说明（少量费用）。

4. 退换货

发现问题 → WhatsApp 发照片给我们 → 按以下处理：

✅

工厂错发（款式/颜色/数量不对）

退换运费由我们承担，直接联系工厂处理。

✅

样品质量问题（≤5件 + ≤¥300）

中国退货运费由我们承担，联系工厂退货退款。

⚠️

批量订单质量问题

我们协助交涉，中国退货运费由买家承担。

📦

国际物流损坏

按物流公司标准赔付（默认赔运费，买保险则按保价赔），我们协助索赔。

❌

买家改变主意

国际+中国退货运费由买家承担，服务费不退。

建议先拿样再批量。样品 ≤5件 + ≤¥300。跳过拿样直接批量的，退换费用买家承担。
