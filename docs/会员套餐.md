# 会员套餐 + 拿样区设计定稿

> 讨论结论：拿样内容不分档，差异全在价格。免费用户「内容放开、只锁折扣」，会员价值靠「300 次分析」在套餐弹层体现。

---

## ① 付费用户 · 拿样卡

```
┌──────────────────────────────────┐
│ 📦 拿样验货                        │
│ ① 付定金 → ② 验货拍照 → ③ 付尾款 → ④ 国际直发 │
│──────────────────────────────────│
│ 定金    ¥55.96                    │
│   商品 ¥45.96 × 1件（MOQ）         │
│   国内邮 ¥10                      │
│──────────────────────────────────│
│ 尾款    $13–16                    │
│   验货确认后付：服务费 $10          │
│   + 国际运费约 $3-6（按实结算）     │
│──────────────────────────────────│
│ ✅ 验货不满意 → 退全部定金          │
│ ✅ 缺货不发货 → 全额退款，帮找同款   │
│                                  │
│  [ 💬 WhatsApp 开始拿样 ]          │
└──────────────────────────────────┘
```

- 4 步流程：付定金 → 验货拍照 → 付尾款 → 国际直发（保留「付尾款」，用户不慌）
- 定金/尾款分块：金额 + 构成小字，用户付什么、我们干什么、收多少，一眼对得上
- 数量锁 MOQ，砍数量选择器，用户不用自己算

## ② 免费用户 · 锁态卡（内容放开，只锁折扣）

```
┌──────────────────────────────────┐
│ 📦 拿样验货                        │
│ ① 付定金 → ② 验货拍照 → ③ 付尾款 → ④ 国际直发 │
│──────────────────────────────────│
│ ⚡ 会员：前 3 次免费 + 之后 $8/次    │
│    免费拿样：$10/次                │
│──────────────────────────────────│
│    [ ⚡ 升级会员 $19.9 ]          │
│    或 WhatsApp 咨询全价拿样        │
└──────────────────────────────────┘
```

- 服务内容（4 步流程）照样展示——用户不知道卖什么就不会付钱
- 「锁」的是价格折扣，不是服务：🔒 文案改成 ⚡ 会员价
- 价差两行摆明（$10/次 vs 会员 3 次免费 + $8），用户自己算「拿 3 次回本」
- 两个出口：升级 / WhatsApp 全价拿样

## 套餐结构（定价 19.9）

| 项 | 免费 | 付费 $19.9 |
|----|------|-----------|
| 定位 | 钓饵·获客 | 入门券·进拿样流程 |
| 分析次数 | 注册送 10 + 每日补齐 3 | 300 总次数，不限时 |
| 拿样服务费 | $10/次（原价） | 前 3 次免费 + 之后 $8（8 折） |
| 历史记录 | 20 条 | 100 条 |
| 拿样区 | 内容放开，只锁折扣 | 全功能 |
