## Phase 1 — 骨架（D1 上午）

| 文件 | 内容 |
|------|------|
| `manifest.json` | Manifest V3，声明 sidePanel + activeTab + host: `*.1688.com` + storage |
| `sidepanel.html` | 5 块 HTML 骨架 + Tab 导航栏 |
| `history.html` | 列表骨架 + 搜索框 |
| `api.js` | 独立 API 封装：fetch 包装 + token 管理 + 异常处理 |
| `i18n.js` | 独立多语言：语言检测 + 翻译函数 t() |

### manifest.json 权限声明
```json
{
  "manifest_version": 3,
  "name": "Sourcely — 1688 供应商背调",
  "permissions": ["sidePanel", "activeTab", "storage"],
  "host_permissions": ["*://*.1688.com/*"],
  "side_panel": { "default_path": "sidepanel.html" }
}
```

## Phase 2 — 分析报告页（D1 下午 + D2 上午）

| 文件 | 内容 |
|------|------|
| `sidepanel.js` | 完整交互逻辑 |
| `sidepanel.css` | 360px 宽度基准样式 |

### 5 块渲染

```
┌─ [分析报告] [历史记录] ──┐
│ ① 商品确认（sticky 顶部）   │
│ ② 综合结论（sticky）       │
├──────────────────────────┤
│ ③ 工厂验证 ▼（可折叠）     │
│ ④ 供应商验证 ▼（可折叠）   │（可滚动）
├──────────────────────────┤
│ ⑤ [我要验货]（sticky 底部）│
└──────────────────────────┘
```

### 交互流

1. 用户打开 1688 产品页 → side panel 自动获取 `chrome.tabs` URL
2. URL → POST `/api/analyze` → 轮询 → 拿到 display JSON
3. 渲染 5 块：productEval + supplierEval + summaryLine

### 状态处理

| 状态 | 展示 |
|------|------|
| 未检测到 1688 URL | "请在 1688 产品页面使用" |
| 分析中 | 骨架屏 + 进度文字 |
| 分析失败 | 错误提示 + 重试按钮 |
| 缓存命中 | 秒出，顶部标注"来自缓存" |
| 首次分析 | 等待 15s，期间显示 Apify 进度 |

## Phase 4 — Badge 提醒 + 登录 + 收尾（D3）

| 文件 | 改动 |
|------|------|
| `manifest.json` | 加 service_worker |
| `static/js/background.js` | Service Worker：检测 URL 变化 → 设 Badge |

### Badge 逻辑

```
用户切换到 1688 产品页
  → background.js 检测 URL 匹配 1688 商品详情
  → 调 API 查缓存
  → 有缓存：setBadgeText('🟢') / setBadgeText('🔴')
  → 无缓存：setBadgeText('🟡')
  → 非 1688 页：清除 Badge
```

### 登录态

- `chrome.storage.local` 存 JWT token
- 插件首次使用 → 弹窗提示登录 → 跳官网 Google 登录 → 回调存 token → 回 side panel
- 已有 token → 直接调 API

### 收尾

- 4 语言 i18n JSON（zh/en/vi/th，初始值从 web 版筛选出插件需要的 key）
- 图标 3 尺寸（16/48/128px）
- 边界 case：网络断开、Token 过期、1688 页面非产品详情、offer_id 解析失败

---

## 与 web/ 的边界

- `extension/` 零文件引用 `web/static/`
- `extension/lang/` 独立 i18n JSON，不跟 web 共享 key
- `extension/static/js/api.js` 独立 API 封装，不 import web/api/core.js
- 后端代码 **零改动**，所有 API 已就位
