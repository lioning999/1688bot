## 1. 错误监控 Sentry

**作用：** 后端代码报错时自动通知你。知道哪里崩了、什么时候崩的、影响了谁。

**场景：** 越南买家凌晨搜了一个链接，后端解析失败。没有 Sentry → 你不知道，他关了页面走人。有 Sentry → 你早上看到告警，修掉。

**实现：**
- `pip install sentry-sdk`
- `main.py` 加 3 行初始化
- `.env` 加 `SENTRY_DSN=xxx`
- 注册 sentry.io 免费账号获取 DSN

**工期：** < 1h | **费用：** $0（免费版月 5000 事件） | **方案文档：** [[设计-错误监控方案.md]]

## 2. GA4 流量分析

**作用：** 知道谁访问网站、从哪来、看了什么、搜了什么。

**场景：** 发现这周 50 个越南 IP 访问 → 验证市场。首页 200 人打开但 10 人搜索 → 首页有问题。有人从 Facebook 帖子进来 → 知道哪个渠道有效。

**实现：**
- 注册 analytics.google.com → 创建 Property → 复制 Measurement ID
- 每页 `<head>` 粘贴 gtag.js 代码（4 行）
- 加 3 个手动事件：搜索、登录、WhatsApp 点击

**工期：** 0.5d | **费用：** $0

## 3. 语言自动检测

**作用：** 用户打开网站 → 自动显示他的浏览器语言。

**场景：** 越南买家打开 → 自动越南语。泰国买家打开 → 自动泰语。不用手动切，降低跳出率。

**实现：**
- 创建 `static/i18n/{en,zh,vi,th,id}.json` 翻译文件
- 新建 `static/js/i18n.js`：读 `navigator.language` → 匹配 → 加载对应 JSON → 遍历 `[data-i18n]` 替换文本
- 用户手动选择存 `localStorage`，优先级高于自动检测

**工期：** 0.5d（代码）+ 1-2d（翻译） | **费用：** $0 | **方案文档：** [[设计-语言自动检测方案.md]]

## 4. 手动语言/国家切换

**作用：** 用户主动选语言 + 国家。语言切换改界面文字，国家切换影响币种和运费估算。

**场景：** 越南人在泰国旅游打开网站（浏览器=越南语，想切成泰语）。一个设备多人共用。自动检测不到的语言 fallback 后用户手动改。

**实现：**
- 基于 #3 翻译系统扩展
- 右上角 `langSwitcher` select 旁边加一个国家选择器
- 选国家 → 联动币种换算 + 运费默认目的国 + 海关提示

**国家-币种-语言：**

| 国家 | 默认语言 | 币种 |
|------|------|------|
| 🇻🇳 越南 | vi | VND |
| 🇮🇩 印尼 | id | IDR |
| 🇹🇭 泰国 | th | THB |
| 🇲🇾 马来西亚 | en/zh | MYR |
| 🌏 其他 | en | USD |

**工期：** 1.5d | **费用：** $0 | **依赖：** #3 先做

## 5. 币种换算

**作用：** 报告里的价格同时显示人民币 + 用户本地币种。越南买家看到 đồng，印尼买家看到 rupiah。

**当前：** 只有 ¥。**改后：** `¥5.80 ≈ ₫19,800`

**实现：**
- 后端启动时从免费汇率 API 拉汇率，存内存，每 6h 刷新
- 前端渲染价格时，根据当前语言取对应币种换算
- 汇率映射：`{vi: 'VND', id: 'IDR', th: 'THB', en: 'USD'}`
- V1 只显示不切换支付币种（支付仍用人民币/美元报价）

**工期：** 0.5d | **费用：** $0（免费汇率 API） | **依赖：** #3 先做
