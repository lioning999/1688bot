## 四、pre-flight 详细说明

### 设计目的

代码改动前的影响面分析。不是全项目审查工具。

### 执行流程

```
步骤0：加载 file-map + 判断意图
  ├─ 定位文件 → 展示文件地图，跳过后续
  └─ 改代码 / 审查 → 继续

步骤1：二问定级
  ① 有没有替换/废弃旧东西？
  ② 涉及几个文件？
  → 定级：🔴 全流程 / 🟡 中 / 🟢 轻

步骤2：按级执行
  🔴 全流程：grep旧符号 + grep新符号 + grep调用方 + 功能完整性清单 + 防御性编程清单
  🟡 中：grep调用方 + 防御性编程清单
  🟢 轻：零额外检查

步骤3：测试卡点（🔴强制暂停）
```

### 适用边界

| ✅ 适用 | ❌ 不适用 |
|---------|----------|
| 改一个函数 | 审查整个项目 |
| 新增一个 API 端点 | 审计文档完整性 |
| 替换旧模块 | 检查跨层契约 |
| 修改数据库字段 | 发现所有技术债 |

## 五、think-tank 详细说明

### 设计目的

把模糊想法变成可执行的决策。5 人核心团队 + 领域专家按需加入。

### 核心团队

| 角色 | 职责 | 一句话 |
|------|------|--------|
| 周鸿祎（主持） | 战略+风险 | "这个方向经不经得起推敲？" |
| 老黄 | 技术落地 | "能做。三天。前提是XX不崩。" |
| 张小龙 | 产品价值 | "用户为什么会需要这个？" |
| 雷军 | 市场竞争 | "好东西自己会走路。" |
| 设计专家 | UI/UX | "好设计让用户感觉不到设计的存在。" |

### 领域专家（按需加入）

- **Dario**（AI）：AI 能力边界/幻觉/成本
- **外贸翻译专家**：术语/措辞/本地化
- **海外本土卖家 × 3**：越南/印尼/泰国卖家视角

### 三种模式

| 模式 | 触发 | 参与 |
|------|------|------|
| 点名 | "老黄，这个方案行不行？" | 只叫被点名的人 |
| 全团 | "智囊团讨论" | 相关角色全部发言 |
| 默认 | 未指定 | 主持人判断领域范围 |

## 六、content-deep-dive 详细说明

### 设计目的

把内容从"说得对"变成"能直接用"。创作者思维，不给建议给成品。

### 铁律

1. 禁止抽象建议（"增强表现力"→ 直接给改写后文案）
2. 逐段输出，不列问题清单
3. 必须带"可拿走的"（模板/标题/checklist）
4. 改动必须对比（❌改前 vs ✅改后）
5. L2/L3 输出三层结构（30秒速览 → 核心改动 → 完整成品）

### 内容类型适配

| 类型 | 额外输出 |
|------|---------|
| 视频脚本 | 画面描述 + 时间标注 + 缩略图 + 发布时间 |
| 技术文章 | 代码对比 + 目录对比 + 概念解释 |
| 营销文案 | A/B 版本 + 多平台适配 |

## 七、idea-evaluator 详细说明

### 设计目的

评估 AI 产品想法是否值得做（go/no-go）。

### 范围

纯软件 + 一人公司 + AI 应用。超出范围告知不适合。

### 五问流程

```
问1：能不能干？— 有人在付钱了吗？（市场）
问2：有没有人干？— 打得过吗？（竞品）
问3：门槛高不高？— 卡在哪？（技术）
问4：挣不挣钱？— 逻辑通吗？（商业模式）
问5：会不会死？— 什么风险一来完蛋？（全员）
```

### 输出

```
📋 [✅ 干 / ⚠️ 谨慎 / ❌ 别干]
五问逐条标记 + 依据等级 [A/B/C] + 综合结论
```

## 八、剩余 skills 速览

### frontend-design

设计独特前端界面，避免 AI 味模板化设计。先出设计计划（配色/字体/布局/签名元素），再写代码。

### theme-factory

10 套预设主题（Ocean Depths、Sunset Boulevard、Forest Canopy 等），可应用到幻灯片/文档/HTML。也支持自定义主题。

### skill-creator

创建/改进 skill 的完整流程：写草稿 → 跑测试 → 评估 → 迭代。支持定性评估和定量 benchmark。

### manage-skills

管理 skill 启用/禁用状态。底层读写 `settings.json` 的 `skillOverrides`。

### resume-team

7 人团队（含 HR 行业专家 + 7 名学生用户代表）按 5 阶段流程讨论简历优化产品。

### ppt-generation

用 AI 生成每页幻灯片图片 → 合成 PPTX。支持 8 种风格。图片逐页顺序生成（每页引用前一页保持一致性）。

## 十、常见问题

### Q: pre-flight 和 全项目审查 有什么区别？

**pre-flight** 是改代码前的"影响面分析"——你明确知道要改什么，它帮你检查遗漏。

**全项目审查** 是"质量审计"——你不知道问题在哪，系统性地扫描发现所有问题。

当前项目**缺少**全项目审查 skill。如需使用，参考 `docs/设计-项目审计Skill方案.md`。

### Q: think-tank 和 idea-evaluator 有什么区别？

**think-tank** 打磨任何想法，输出多角度审视。
**idea-evaluator** 专门评估"这个产品要不要做"，输出 go/no-go 决策。

think-tank 是通用工具，idea-evaluator 是专用工具。

### Q: 什么时候用 file-map 而不是直接 grep？

**file-map** 告诉你"改 X 应该去哪个文件"——你不确定文件位置时。

**grep** 告诉你"这个符号在哪里被引用"——你已经知道文件，想查影响面时。

pre-flight 步骤0 已经帮你加载了 file-map，大多数情况下不需要手动调用。
