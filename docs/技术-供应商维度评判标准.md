## 一、输入字段

| 字段 | 来源 | 类型 | 说明 |

## 二、三维度分档表

### D1 — 🏭 身份（是不是工厂？）

| 档位 | 条件 | score | 标签 |
|:--|:--|:--|:--|
| 🟢 认证工厂 | `seller_type in ("super_factory","flagship")` 或 `factory_flags` 含 超级工厂/源头旗舰/实力工厂 | 3 | `🏭认证工厂` |
| 🟡 普通工厂 | `factory_flags` 含 源头工厂/生产厂家/工厂直供/通品工厂 且 不含"非生产厂家" | 2 | `🏭工厂直供` |
| 🔴 贸易商 | `factory_flags` 含"非生产厂家" 或 `seller_type` 为 trader/普通商家 | 1 | `⚠️贸易商` |
| ⬜ 缺 | 无有效数据 | 0 | — |

**判定顺序：** 先判认证工厂 → 再判贸易商 → 剩余归普通工厂。避免重叠。

### D2 — 📋 认证（有没有人验过？）

| 档位 | 条件 | score | 标签 |
|:--|:--|:--|:--|
| 🟢 深度 | `cert_type` 含 深度验厂/深度认证/SGS/tuv/TUV | 3 | `📋深度验厂` |
| 🟡 基础 | `cert_type` 含 实地认证/第三方验厂/实地认证 | 2 | — |
| 🔴 无 | `cert_type` 为空/null/"暂无认证" | 1 | — |
| ⬜ 缺 | 无数据 | 0 | — |

### D3 — 📅 年限（干了多久？）

| 档位 | 条件 | score | 标签 |
|:--|:--|:--|:--|
| 🟢 老店 | `shop_years >= 3` | 3 | `📅老店` |
| 🟡 中等 | `1 <= shop_years < 3` | 2 | — |
| 🔴 新店 | `shop_years < 1` | 1 | `📅新店` |
| ⬜ 缺 | `shop_years is None` | 0 | — |

---

## 三、计分规则

```python
total_score = D1.score + D2.score + D3.score  # 范围: 0 ~ 9
```

---

## 四、等级映射

| total_score | 等级 | 含义 |
|:--|:--|:--|
| 7 – 9 | ✅ 可信 | 资质充分，可放心合作 |
| 4 – 6 | ⚠️ 可合作 | 有一定资质，建议验货确认 |
| 1 – 3 | 🔴 谨慎 | 资质不足，需验证后再决定 |
| 0 | ⬜ 数据不足 | 无有效数据，自行评估 |

---

## 五、输出三行

### 等级行

```
✅ 可信 / ⚠️ 可合作 / 🔴 谨慎 / ⬜ 数据不足
```

### 标签行

规则：🟢 档和 🔴 档（风险信号）亮标签。🟡 档不亮。

```
可能出现的标签：
  🟢: 🏭认证工厂, 🏭工厂直供, 📋深度验厂, 📅老店
  🔴: ⚠️贸易商, 📅新店

拼接符: " · "
无标签: ""（空）
```

示例：
- 认证工厂+深度验厂+老店 → `🏭认证工厂 · 📋深度验厂 · 📅老店`
- 普通工厂+无认证+新店 → `🏭工厂直供 · 📅新店`
- 贸易商+深度验厂+老店 → `⚠️贸易商 · 📋深度验厂 · 📅老店`

### 人话行

人话由身份驱动（认证工厂 / 普通工厂 / 贸易商），认证和年限为修饰参数。8 条模板：

| # | 触发条件 | 人话（zh） |
|:--|:--|:--|
| T1 | 认证工厂 + 老店 + 深度认证 | 平台认证源头工厂，{years}年老店，深度验厂背书。放心长期合作，拿样确认款式即可批量。 |
| T2 | 认证工厂 + 老店 + 基础/无认证 | 平台认证源头工厂，{years}年老店。资质可靠，建议拿样确认品质后批量。 |
| T3 | 认证工厂 + 非老店 | 平台认证工厂，经营{desc}。认证有背书但{reason}。建议拿样验证产能和品质。 |
| T4 | 普通工厂 + 老店 + 有认证 | 工厂直供，{years}年老店，{cert}认证。可放心合作，拿样确认品质后批量。 |
| T5 | 普通工厂 + 老店 + 无认证 | 工厂直供，{years}年老店，但无第三方认证。建议拿样验货确认品质再批量。 |
| T6 | 普通工厂 + 非老店 | 工厂直供，{desc}。资质待更多验证，建议先拿单样验货再决定。 |
| T7 | 贸易商 + 老店 + 有认证 | 贸易商非源头工厂，但{years}年老店+{cert}认证信誉可查。拿样对比价格，品质OK后可长期合作。 |
| T8 | 贸易商 + 非老店或无认证 | 贸易商拿货非源头。{reasons}。先拿样验货，确认品质和价格后再决定是否批量。 |
| T0 | 数据不足 | 供应商数据不足，无法判断靠谱度。建议拿样后自行评估。 |

**参数说明：**

| 参数 | 取值逻辑 |
|:--|:--|
| `{years}` | `shop_years` 数字 |
| `{cert}` | "深度验厂" / "实地认证"（取 cert_type 原文） |
| `{desc}` | 根据年限和认证拼接，如"1年+"、"不足1年"、"无认证" |
| `{reason}` | 如"年限尚短"、"认证等级不高" |

## 六、伪代码

```python
def evaluate_supplier(factory_flags, seller_type, cert_type, shop_years):
    """返回 { grade, labels, human, score }"""

    # ---- D1 身份 ----
    is_advanced = (
        seller_type in ("super_factory", "flagship")
        or any(kw in (factory_flags or "") for kw in ("超级工厂", "源头旗舰", "实力工厂"))
    )
    is_trader = (
        "非生产厂家" in (factory_flags or "")
        or seller_type in ("trader",)
    )
    is_factory = (
        any(kw in (factory_flags or "") for kw in (
            "源头工厂", "生产厂家", "工厂直供", "通品工厂"
        ))
    )

    if factory_flags is None and seller_type is None:
        d1_score, d1_label = 0, None
    elif is_advanced:
        d1_score, d1_label = 3, "🏭认证工厂"
    elif is_trader:
        d1_score, d1_label = 1, "⚠️贸易商"
    elif is_factory:
        d1_score, d1_label = 2, "🏭工厂直供"
    else:
        d1_score, d1_label = 1, "⚠️贸易商"  # 兜底

    # ---- D2 认证 ----
    cert_lower = (cert_type or "").lower()
    if cert_type is None:
        d2_score, d2_label = 0, None
    elif any(kw in cert_lower for kw in ("深度验厂", "深度认证", "sgs", "tuv")):
        d2_score, d2_label = 3, "📋深度验厂"
    elif any(kw in cert_lower for kw in ("实地认证", "第三方验厂", "实地认证")):
        d2_score, d2_label = 2, None
    else:
        d2_score, d2_label = 1, None

    # ---- D3 年限 ----
    if shop_years is None:
        d3_score, d3_label = 0, None
    elif shop_years >= 3:
        d3_score, d3_label = 3, "📅老店"
    elif shop_years >= 1:
        d3_score, d3_label = 2, None
    else:
        d3_score, d3_label = 1, "📅新店"

    # ---- 总分 + 等级 ----
    total = d1_score + d2_score + d3_score
    if total >= 7:    grade = "✅ 可信"
    elif total >= 4:  grade = "⚠️ 可合作"
    elif total >= 1:  grade = "🔴 谨慎"
    else:             grade = "⬜ 数据不足"

    # ---- 标签行 ----
    labels = [l for l in (d1_label, d2_label, d3_label) if l]
    label_str = " · ".join(labels)

    # ---- 人话行 ----
    human_key = _select_human_template(
        identity=(d1_score, d1_label),
        cert=(d2_score, d2_label),
        years=(d3_score, d3_label, shop_years),
        total=total,
    )
    human = _render_human(human_key, shop_years, cert_type, factory_flags)

    return {"grade": grade, "labels": label_str, "human": human, "score": total}


def _select_human_template(identity, cert, years, total):
    """按身份驱动选择人话模板 KEY。"""
    d1s, d1l = identity
    d2s, d2l = cert
    d3s, d3l, yrs = years

    if d1s == 0 and d2s == 0 and d3s == 0:
        return "supplier_human_no_data"

    is_old = d3s == 3       # ≥3年
    is_not_old = d3s <= 2   # <3年（含缺）
    has_deep_cert = d2s == 3
    has_any_cert = d2s >= 2

    if d1l == "🏭认证工厂":
        if is_old and has_deep_cert:   return "supplier_human_t1"
        if is_old and not has_deep_cert: return "supplier_human_t2"
        return "supplier_human_t3"

    if d1l == "🏭工厂直供":
        if is_old and has_any_cert:    return "supplier_human_t4"
        if is_old and not has_any_cert: return "supplier_human_t5"
        return "supplier_human_t6"

    if d1l == "⚠️贸易商" or d1s == 1:
        if is_old and has_any_cert:    return "supplier_human_t7"
        return "supplier_human_t8"

    return "supplier_human_no_data"
```
