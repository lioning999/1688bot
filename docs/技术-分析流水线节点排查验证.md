## 排查方法

每个节点出一张「验证卡片」：**文档说啥 / 代码实际（带行号）/ 判定 ✅❌⚠️**。

重点核查三个最容易漏的点：

1. **配额对称性** — 扣了几次（`decrement_quota`），每个失败/命中的出口是否都退了（`increment_quota`）。多退 / 漏退 / 重复退。
2. **字段名** — `raw_json` / `result_json` / `display_i18n` 是否读写一致（上次核心 bug 就是 key 不匹配）。
3. **边界** — 命中语言判断、`save_lang` 归一化、清理上限。
