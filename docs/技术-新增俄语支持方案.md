# 技术-新增俄语支持方案

> 为 Sourcely 增加俄语（ru）语言支持。当前语言：zh/en/vi/th（4 语言）。目标：5 语言。
> 基于实际 grep 确认的文件清单（2026-08-27），非推测。

---

## 现状

翻译三层结构：

| 层 | 管什么 | 语言落点 |
|----|--------|---------|
| ① 前端 i18n | 页面壳文案（按钮/标签/提示） | `src/chrome-ext/lang/{zh,en,vi,th}.json` |
| ② glossary 字典 | 判词/术语/维度名（可穷举） | `src/api/domain/data/glossary.json`（240 个 key × 4 语言） |
| ③ Qwen AI | 1688 动态中文（标题/判词语优化） | `verdict_prompts.json`（en/vi/th 三套母语 prompt，zh 走模板） |

辅助：`_make_money()`（ai_verdict_svc.py）按语言返回本地货币（en=$ / vi=₫ / th=฿）。
