# 评分标准与标签体系（定稿 · 开发用）

> 最后更新：2026-08-06 | 生命周期：活跃
> 可直接按此文档开发 evaluator.py + display_builder.py + term_glossary.json

---

## 核心定位

1. 这东西能卖吗？  → 需要结论（能/不能/试试看）
2. 为什么？        → 需要依据（哪个维度好、哪个不行）
3. 我该干什么？    → 需要行动（拿样/跳过/收藏）
对应
- **产品判词答："这个品能不能帮我赚钱？"**
- **供应商判词答："这个厂能不能信？会不会坑我？"**
- **综合判词答："这一单，该不该花钱？前提条件是什么？"**

**判词系统是安检门，不是导购。** 能筛掉烂品、标记风险，但不能替用户选品。

**核心原则：**
1. 致命短板一票否决——加法不能掩盖致命伤
2. 复购未知 ≠ 复购低——数据缺不等于信号差
3. 热销+高关注=当前热度验证过——不是过气款
4. 档位区分度优先——不能大部分品进同一档
5. 判词可核对——每个结论背后有具体的维度信号支撑

## 一、产品判词

### 1.1 致命短板（一票否决 → 🔴 换品）

| 信号 | 触发条件 | 说明 |
|------|------|------|
| 🚫 不支持退货 | return7day ≠ OK（已知不支持） | 卖出去退不回来，差评降权扛不住 |
| ⚠️ 差评偏多 | positive_rate < 80% | 品控有问题。接口保留，数据到位后启用 |

> **注意：退货未知（return7day=0/缺失）≠ 不支持退货，不触发致命。** 仅 serviceLabels 明确不含"7天无理由退货"时才算。

### 1.2 数据不足（→ ⬜ 跳过）

| 条件 | 说明 |
|------|------|
| 销量 + 复购 + 退货 ≥ 2 项缺失 | 关键数据不够，无法判断 |
| 销量未知 ∧ 复购未知 ∧ 退货未知 | 三项核心全空 |

### 1.3 档位判定（按顺序匹配，命中即停）

```
 1. 致命短板命中                                         → 🔴 换品
 2. 销量 + 复购 + 退货 ≥ 2 项缺失                         → ⬜ 跳过
 3. 🔄高复购(>30%) ∧ 销量>100 ∧ 无致命                    → 🟢 值得做
 4. 🔥热销(>1000) ∧ 👀高关注(>100) ∧ 无致命              → 🟢 值得做    ← 双热信号，复购未知不降级
 5. 🔥热销(>1000) ∧ 🔄复购>10% ∧ 无致命                  → 🟢 值得做
 6. 🔥热销(>1000) ∧ 复购未知 ∧ 关注≤100                   → 🟡 小批量试   ← 热销但缺复购+当前热度不高
 7. 🔥热销(>1000) ∧ 复购≤10% ∧ 无致命                     → 🟡 谨慎      ← 已知低复购=过气风险
 8. 👀高关注(>100) ∧ 低销量(≤100) ∧ 无致命               → 🟡 小批量试
 9. 🔄高复购(>30%) ∧ 销量≤100 ∧ 无致命                   → 🟡 谨慎      ← 样本太小
10. 中等亮点 ≥ 3 项                                      → 🟡 小批量试
11. 中等亮点 1–2 项                                      → ⬜ 观望      ← 收紧：信号不够，不硬推
12. 其余（全维度平平 / 新品无销量）                        → ⬜ 观望
```

**中等亮点清单（5 个）：**
- 📈 潜力产品（100 < sold ≤ 1000）
- 🔄 一般复购（10% < repurchase ≤ 30%）
- 💰 超值（price<20 ∧ moq≤10）
- 👀 高关注（wantBuy > 100）
- 🛡️ 支持退货（return7day = OK）

### 1.4 跨维度打架（压制规则）

以下情况强制降一档（仅当匹配到🟢时生效）：

| 打架信号 | 压制 | 说明 |
|------|:--:|------|
| 🔥热销(>1000) + 🕳️低复购(≤10%) | 🟢→🟡 | 卖得多但没人回购=过气/流量款 |
| 👀高关注(>100) + 🌱低销量(≤100) | 🟢→🟡 | 很多人看但不买=品有疑点 |

### 1.5 文案表

| 档位 | 条件 | 文案（zh） |
|:--:|------|------|
| 🔴 换品 | 不支持退货 | **换品。** 不支持退货——卖出去退不回来，差评降权你扛不住。别碰这个品 |
| 🔴 换品 | 差评<80%* | **换品。** 差评太多——品控不行，售后会吃掉利润，还会拖累全店权重 |
| ⬜ 跳过 | ≥2项核心缺失 | **跳过。** 关键数据缺太多，判断不了能不能赚钱。别给看不清的东西花时间 |
| ⬜ 跳过 | 三项核心全空 | **跳过。** 销量、复购、退货全空，跟没查一样。别为盲盒花拿样钱 |
| 🟢 值得做 | 🔄高复购(>30%) ∧ 销量>100 | **值得做。** 有销量打底 + 买过的人会回来补货——品稳、有需求。{门槛} |
| 🟢 值得做 | 🔥热销 ∧ 👀高关注 | **值得做。** 卖得火 + 当前热度高——需求被两次验证过（过去+现在）。{门槛} |
| 🟢 值得做 | 🔥热销 ∧ 🔄复购>10% | **值得做。** 卖得火 + 有回头客——销量和品质都验证过，最稳的信号。{门槛} |
| 🟡 小批量试 | 🔥热销 ∧ 复购未知 ∧ 关注≤100 | **小批量试。** 卖得火但缺复购数据、当前热度也不高——有两头空的可能。少量拿，别压货。{门槛} |
| 🟡 小批量试 | 🔥热销 ∧ 退货未知 | **小批量试。** 卖得火但没有退货信息——不知道能不能退。先少量拿，万一砸了损失可控。{门槛} |
| 🟡 小批量试 | 👀高关注 ∧ 🌱低销量 | **小批量试。** 很多人想看但还没人买——可能有潜力，也可能品有问题劝退买家。先少量拿测水，别压货。{门槛} |
| 🟡 小批量试 | 中等亮点 ≥ 3 | **小批量试。** 多项指标还行，但缺爆点。先少量拿测真实需求，跑通再追加。{门槛} |
| 🟡 谨慎 | 🔥热销 ∧ 🕳️复购≤10% | **谨慎。** 卖得火但没什么人回购——大概率过气款/流量款，后续需求没保证。想清楚再下手，别压货。{门槛} |
| 🟡 谨慎 | 🔄高复购(>30%) ∧ 销量≤100 | **谨慎。** 复购高但卖得太少——样本不够，如果只卖了10件，30%复购也就3个人。先观察，等销量起来再说。{门槛} |
| ⬜ 观望 | 中等亮点 1–2 | **观望。** 有零星亮点但撑不起来。先收藏蹲数据，别急着下手。{门槛} |
| ⬜ 观望 | 全维度平平/新品/退货缺失 | **观望。** 表现普通/数据太薄，没足够信号支撑判断。先收藏蹲数据，别第一个冲 |

*差评<80%：接口保留，positive_rate 数据到位后启用。

### 1.6 短板文案模板

| 短板 | 文案 |
|------|------|
| 复购低/未知 | 回头客少，可能是一次性款 |
| 门槛高 | 起批/单价偏高 |
| 关注低 | 没什么人看，需求热度低 |
| 口碑<95% | 好评率偏低 |

### 1.7 门槛附言模板

| 门槛档 | 附言 |
|------|------|
| 💰 超值（price<20 ∧ moq≤10） | 试错成本极低，拿样基本不亏 |
| 💰 一般（price<50 ∧ moq≤100） | 试错成本可控 |
| 🧱 高成本（其他） | 留意：{moq}件起批，试错一次≈{price×moq}元，先算账 |

## 二、供应商判词

### 2.1 致命短板（一票否决 → 🔴 别碰）

| 条件 | 说明 |
|------|------|
| 身份未知 ∧ 认证未知 ∧ 年限未知 | 三项全空=黑箱，对面是谁都不知道 |

### 2.2 数据不足（→ ⬜ 跳过）

| 条件 | 说明 |
|------|------|
| 身份 + 年限 ≥ 2 项缺失 | 关键信息不够 |

### 2.3 档位判定（按顺序匹配，命中即停）

**信号强度定义：**

| 强度 | 身份 | 认证 | 年限 |
|:--:|------|------|------|
| 强 | 实力工厂/源头旗舰/超级工厂/实力商家 | 深度验厂/SGS/TUV | 老店(≥3年) |
| 中等 | 生产厂家/工厂直供/normal_factory | 基础认证(实地认证/第三方验厂等) | 有经验(1-3年) |
| 弱 | 贸易商/普通商家 | 无认证/为空 | 新店(<1年) |

**判定规则：**

```
1. 身份 + 认证 + 年限 全空                         → 🔴 别碰
2. 身份 + 年限 ≥ 2 项缺失                          → ⬜ 跳过
3. 强信号 ≥ 2 项                                   → 🟢 可信
4. 强信号 = 1 项 ∨ 中等信号 ≥ 2 项                  → 🟡 可用
5. 弱信号 ≥ 2 项                                   → 🟡 谨慎
6. 其余                                            → 🟡 谨慎
```

### 2.4 文案表

| 档位 | 条件 | 文案（zh） |
|:--:|------|------|
| 🔴 别碰 | 三项全空 | **别碰。** 对面是谁都不知道，没法追溯，出了事你连人都找不到 |
| ⬜ 跳过 | 身份+年限 ≥2 缺失 | **跳过。** 关键信息不够，判断不了这个厂靠不靠谱 |
| 🟢 可信 | 强信号 ≥ 2（典型：实力工厂+深度认证+老店） | **可信。** {好的}。拿样确认款式，可放心合作 |
| 🟡 可用 | 强信号=1 或 中等≥2（典型：生产厂家+老店+无认证） | **可用。** {好的}。但{不好的}。{动作} |
| 🟡 谨慎 | 弱信号 ≥ 2（典型：贸易商+新店+无认证） | **谨慎。** {不好的}——{具体风险}。{动作} |

### 2.5 信号→文案片段映射

**好的信号文案：**

| 信号 | 文案片段 |
|------|------|
| 🏭 实力工厂/源头旗舰/超级工厂 | 实力工厂——有实体可追溯 |
| 🏭 生产厂家/工厂直供 | 工厂直供——跳过中间商 |
| 📋 深度验厂/SGS/TUV | {cert}认证——有第三方背书 |
| 📋 基础认证 | 有{认证类型}，基本面过关 |
| 📅 老店(≥3年) | 干了{n}年——能活下来的不会太差 |

**不好的信号文案：**

| 信号 | 文案片段 |
|------|------|
| 🏬 贸易商 | 贸易商拿货，不是源头——价格有加价 |
| 📋 无认证 | 没人验过厂——品质靠你自己判断 |
| 📅 新店(<1年) | 新店——稳定性还没被验证 |

**动作建议映射：**

| 短板组合 | 动作 |
|------|------|
| 无认证 | 拿样时仔细验货 |
| 贸易商 | 拿样后先比价，确认有价格优势再合作 |
| 新店 | 拿样确认交期稳不稳 |
| 贸易商+无认证 | 先比价再拿样，别急着批量 |
| 无致命短板 | 拿样确认款式后可放心合作 |

## 三、综合判词

### 3.1 核心原则

综合判词不做第三个独立判断，而是**"产品 × 供应商交叉解读"**——回答：**"这一单，该不该花钱？最大风险在哪一边？"**

**弱者定天花板。** 一方致命=全局否定。一方跳过=等一等。

### 3.2 判定规则

| 产品→ 供应商↓ | 🟢可信 | 🟡可用 | 🟡谨慎 | 🔴别碰 | ⬜跳过 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| 🟢值得做 | 🟢出手 | 🟢出手 | 🟡有条件 | 🔴不建议 | ⬜等一等 |
| 🟡小批量试 | 🟡有条件 | 🟡有条件 | 🟡有条件 | 🔴不建议 | ⬜等一等 |
| 🟡谨慎 | 🟡有条件 | 🟡有条件 | 🟡有条件 | 🔴不建议 | ⬜等一等 |
| ⬜观望 | ⬜等一等 | ⬜等一等 | ⬜等一等 | 🔴不建议 | ⬜等一等 |
| 🔴换品 | 🔴不建议 | 🔴不建议 | 🔴不建议 | 🔴不建议 | 🔴不建议 |
| ⬜跳过 | ⬜等一等 | ⬜等一等 | ⬜等一等 | 🔴不建议 | ⬜等一等 |

### 3.3 文案表

| 综合 | 条件 | 文案（zh） |
|:--:|------|------|
| 🟢 可以出手 | 品≥🟢 ∧ 厂≥🟢 | **可以出手。** 品验证过，厂靠得住。{剩余风险}拿样确认，可以放心做 |
| 🟢 可以出手 | 品🟢 ∧ 厂🟡可用 | **可以出手。** 品没问题。厂基本面OK但缺顶级背书——拿样时多留个心眼验货。{门槛} |
| 🟡 有条件做 | 品≥🟡 ∧ 厂=🟢 | **有条件做，别压货。** 厂靠得住，但品还没完全验证。先少量拿，卖动了厂能跟上。{门槛} |
| 🟡 有条件做 | 品≥🟡 ∧ 厂=🟡 | **有条件做。** {品弱：品要测 / 厂弱：厂要验}。拿最少批量试水，同时验货，两件事一起做别分开花钱。{门槛} |
| 🔴 不建议 | 品🔴 ∨ 厂🔴 | **不建议。** {品致命：不支持退货，硬伤在品，换品 / 厂致命：黑箱供应商，硬伤在厂，换厂}。别在这一单上花钱 |
| ⬜ 等一等 | 品⬜ ∨ 厂⬜ ∨ 双弱 | **等一等。** {品/厂数据不够}——判断不了。先收藏，别急着花钱 |

## 四、辅助判词

以下判词从产品/供应商结论直接推导，不新增判断逻辑。

### 4.1 产品组头摘要

| 产品档位 | 摘要文案 |
|:--:|------|
| 🟢 值得做 | 产品验证过，值得做 |
| 🟡 小批量试 | 产品有支撑，需验证 |
| 🟡 谨慎 | 产品信号偏弱 |
| ⬜ 观望/跳过 | 产品数据不足 |
| 🔴 换品 | 产品有硬伤 |

### 4.2 供应商组头摘要

| 供应商档位 | 摘要文案 |
|:--:|------|
| 🟢 可信 | 供应商可信 |
| 🟡 可用 | 供应商可用，留意短板 |
| 🟡 谨慎 | 供应商信号偏弱 |
| ⬜ 跳过 | 供应商信息不足 |
| 🔴 别碰 | 供应商有硬伤 |

### 4.3 注意事项（风险汇总）

从产品/供应商判词中提取"不好的信号"汇总展示：

| 来源 | 触发条件 | 注意事项文案 |
|------|------|------|

### 5.2 evaluator.py 核心结构（建议）

```python
def evaluate_product(mapped: dict[str, Any]) -> dict[str, Any]:
    signals = _product_signals(mapped)        # 提取6维信号 + 标签
    fatal = _product_fatal(signals)            # 致命短板检查
    if fatal: return fatal_verdict
    
    missing = _product_missing(signals)        # 数据缺失检查
    if missing: return skip_verdict
    
    tier = _product_tier(signals)              # 档位判定（按顺序匹配）
    return _product_verdict(tier, signals)     # 组装 verdict dict

def evaluate_supplier(mapped: dict[str, Any]) -> dict[str, Any]:
    signals = _supplier_signals(mapped)        # 提取3维信号强度
    fatal = _supplier_fatal(signals)
    if fatal: return fatal_verdict
    
    missing = _supplier_missing(signals)
    if missing: return skip_verdict
    
    tier = _supplier_tier(signals)             # 信号强度计数→档位
    return _supplier_verdict(tier, signals)

def evaluate_summary(product: dict, supplier: dict) -> dict[str, Any]:
    p_tier = product["tier"]                   # "go" / "trial" / "caution" / "skip" / "fatal" / "watch"
    s_tier = supplier["tier"]
    summary_tier = SUMMARY_MATRIX[p_tier][s_tier]
    return _summary_verdict(summary_tier, product, supplier)
```
