# 维度一：货品（市场验证）— 评判标准

> 目录：输入字段 · 四维度分档 · 计分规则 · 输出三行 · 伪代码 · 验证用例 · 实现位置
> 生命周期：活跃（V1 实现中）

---

## 一、输入字段

| 字段 | 来源 | 类型 | 说明 |
|:--|:--|:--|:--|
| `price` | Apify `offer.price` | float | 单价（元），取最低档 |
| `moq` | Apify `offer.moq` | int | 最小起订量 |
| `sales_30d` | Apify `trade.sales30d` | int | 近30天销量 |
| `repurchase_rate` | Apify `trade.repurchaseRate` | float | 复购率（百分比） |
| `positive_rate` | Apify `trade.positiveRate` | float | 好评率（百分比） |

---

## 二、四维度分档表

### D1 — 销量（这个货卖得动吗？）

| 档位 | 条件 (Python) | score | 标签 |
|:--|:--|:--|:--|
| 🟢 好 | `sales_30d and sales_30d > 1000` | 3 | `🔥热销品` |
| 🟡 中 | `sales_30d and 100 < sales_30d <= 1000` | 2 | — |
| 🔴 低 | `sales_30d and sales_30d <= 100` | 1 | — |
| ⬜ 缺 | `sales_30d is None` | 0 | — |

### D2 — 复购（买过的人还会补货吗？）

| 档位 | 条件 | score | 标签 |
|:--|:--|:--|:--|
| 🟢 好 | `repurchase_rate and repurchase_rate > 30` | 3 | `🔄高复购` |
| 🟡 中 | `repurchase_rate and 10 < repurchase_rate <= 30` | 2 | — |
| 🔴 低 | `repurchase_rate and repurchase_rate <= 10` | 1 | — |
| ⬜ 缺 | `repurchase_rate is None` | 0 | — |

### D3 — 门槛（试错会不会亏很多？）

| 档位 | 条件 | score | 标签 |
|:--|:--|:--|:--|
| 🟢 好 | `price and moq and price < 20 and moq <= 10` | 3 | `💰低门槛` |
| 🟡 中 | `price and moq and price < 50 and moq <= 100 and not (price < 20 and moq <= 10)` | 2 | — |
| 🔴 高 | `price and moq and (price >= 50 or moq > 100)` | 1 | — |
| ⬜ 缺 | `price is None or moq is None` | 0 | — |

### D4 — 口碑（收货人满意吗？）

| 档位 | 条件 | score | 标签 |
|:--|:--|:--|:--|
| 🟢 好 | `positive_rate and positive_rate >= 98` | 3 | `⭐口碑好` |
| 🟡 中 | `positive_rate and 95 <= positive_rate < 98` | 2 | — |
| 🔴 低 | `positive_rate and positive_rate < 95` | 1 | — |
| ⬜ 缺 | `positive_rate is None` | 0 | — |

## 三、计分规则

```python
total_score = D1.score + D2.score + D3.score + D4.score  # 范围: 0 ~ 12
```

---

## 四、输出三行

### 标签行

```
= 所有 🟢 档位标签用 " · " 拼接
= 无 🟢 档位 → ""（空字符串）
```

示例：
- 全绿: `🔥热销品 · 🔄高复购 · 💰低门槛 · ⭐口碑好`
- 仅销量+门槛: `🔥热销品 · 💰低门槛`
- 全灭: ``（空）

### 数据行

```
= 有数据的维度拼接，格式见下表
= 全部缺失 → "线上数据不足"
```

每个维度有数据时的格式：

| 维度 | 有数据时格式 | 示例 |
|:--|:--|:--|
| D1 销量 | `月销{sales_30d}+` | `月销8900+` |
| D2 复购 | `复购{repurchase_rate}%` | `复购67.5%` |
| D3 门槛 | `¥{price}/件 · 起订{moq}件` | `¥2/件 · 起订2件` |
| D4 口碑 | `好评{positive_rate}%` | `好评99.6%` |

拼接符：` · `（中间点加空格）

### 人话行

| total_score | 人话 |
|:--|:--|
| 10 – 12 | 市场反复验证，数据全面优秀，试错成本低，放心拿样 |
| 7 – 9 | 市场验证较好，数据整体不错，建议拿样进一步确认品质 |
| 4 – 6 | 线上数据中等，有亮点也有不足，拿样自行判断更稳妥 |
| 1 – 3 | 线上数据偏少，市场验证不充分，建议小批量试水 |
| 0 | 暂无足够线上数据，建议拿样后自行评估是否批量 |

## 五、伪代码

```python
def evaluate_product(price, moq, sales_30d, repurchase_rate, positive_rate):
    """返回 { labels, data, human, score }"""

    # Step 1: 各维度定档
    dims = {}

    # D1 销量
    if sales_30d is None:       dims['d1'] = {'score':0, 'label':None}
    elif sales_30d > 1000:      dims['d1'] = {'score':3, 'label':'🔥热销品'}
    elif sales_30d > 100:       dims['d1'] = {'score':2, 'label':None}
    else:                       dims['d1'] = {'score':1, 'label':None}

    # D2 复购
    if repurchase_rate is None: dims['d2'] = {'score':0, 'label':None}
    elif repurchase_rate > 30:  dims['d2'] = {'score':3, 'label':'🔄高复购'}
    elif repurchase_rate > 10:  dims['d2'] = {'score':2, 'label':None}
    else:                       dims['d2'] = {'score':1, 'label':None}

    # D3 门槛
    if price is None or moq is None: dims['d3'] = {'score':0, 'label':None}
    elif price < 20 and moq <= 10:   dims['d3'] = {'score':3, 'label':'💰低门槛'}
    elif price < 50 and moq <= 100:  dims['d3'] = {'score':2, 'label':None}
    else:                            dims['d3'] = {'score':1, 'label':None}

    # D4 口碑
    if positive_rate is None:   dims['d4'] = {'score':0, 'label':None}
    elif positive_rate >= 98:   dims['d4'] = {'score':3, 'label':'⭐口碑好'}
    elif positive_rate >= 95:   dims['d4'] = {'score':2, 'label':None}
    else:                       dims['d4'] = {'score':1, 'label':None}

    # Step 2: 标签行
    labels = [d['label'] for d in dims.values() if d['label']]
    label_str = ' · '.join(labels) if labels else ''

    # Step 3: 数据行
    parts = []
    if sales_30d is not None:       parts.append(f'月销{sales_30d}+')
    if repurchase_rate is not None: parts.append(f'复购{repurchase_rate}%')
    if price is not None and moq is not None:
        parts.append(f'¥{price}/件 · 起订{moq}件')
    elif price is not None:
        parts.append(f'¥{price}/件')
    if positive_rate is not None:   parts.append(f'好评{positive_rate}%')
    data_str = ' · '.join(parts) if parts else '线上数据不足'

    # Step 4: 总分 + 人话
    total = sum(d['score'] for d in dims.values())
    human_map = {
        range(10,13): '市场反复验证，数据全面优秀，试错成本低，放心拿样',
        range(7,10):  '市场验证较好，数据整体不错，建议拿样进一步确认品质',
        range(4,7):   '线上数据中等，有亮点也有不足，拿样自行判断更稳妥',
        range(1,4):   '线上数据偏少，市场验证不充分，建议小批量试水',
    }
    human = '暂无足够线上数据，建议拿样后自行评估是否批量'
    for r, txt in human_map.items():
        if total in r:
            human = txt
            break

    return {'labels': label_str, 'data': data_str, 'human': human, 'score': total}
```
