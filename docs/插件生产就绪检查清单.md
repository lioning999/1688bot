1. MV3 框架：✅ 规范，没问题

SidePanel ──sendMessage──▶ Service Worker ──fetch──▶ FastAPI
 (纯UI,零fetch)           (唯一网络出口)            (业务逻辑)
这个架构就是 MV3 标准答案。对照 Chrome 官方文档：

检查点	状态
manifest.json manifest_version: 3	✅
background 用 service_worker 不用 scripts	✅
host_permissions 声明 API 域名	✅
side_panel.default_path	✅
SW 是唯一 fetch 出口	✅
UI 通过 sendMessage 通信	✅
return true 异步响应	✅
Token 存 chrome.storage.local，SW 自取	✅
Google OAuth 用 launchWebAuthFlow 在 SW 里调	✅
文件命名：service-worker.js（官方推荐名）	✅
骨架没问题。 不规范的全在细节层——字段名写错、渲染漏段、缺超时控制——这些不是框架问题，是执行问题。
