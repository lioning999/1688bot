## 二、报告页 — 分析流程（report.html）

### 2.1 中文用户 — 完整分析
| # | 步骤 | 预期 |

| 2 | 检查商品标题 | 显示 1688 中文原文 |

| 4 | 检查 Badge 标签 | 标签为中文（如"7天无理由退货"、"支持混批"） |
| 5 | 检查判词（产品/工厂/拿样 Tab） | 判词为中文 |
| 6 | 检查工厂信息 Tab | sellerLabel、factoryFlags、解释文案均为中文 |
| 7 | 检查 SKU 名称 | 中文原文 |
| 8 | 检查产业带解释（地址行） | 如"义乌/金华 — 中国最大小商品集散地"为中文 |

### 2.2 非中文用户 — 完整分析（依次测 en / vi / th / id，至少测 en + vi）
| # | 步骤 | 预期 |
|---|------|------|
| 1 | 切语言 → 粘贴 1688 URL → 等待完成 | 报告渲染 |
| 2 | 检查商品标题 | **翻译后**的目标语言（非中文） |
| 3 | 检查 factoryFlags（工厂标签行） | 目标语言（如 vi: "Nhà máy siêu cấp" 非中文"超级工厂"） |
| 4 | 检查 supplierName / shippingLocation | 目标语言 |
| 5 | 检查 specs（规格参数 name+value） | **全部**翻译为目标语言，无中文残留 |
| 6 | 检查 SKU 名称 | 目标语言 |
| 7 | 检查判词 | 判词为目标语言 |
| 8 | 检查 Badge | 标签为目标语言 |
| 9 | 检查 trustBar（sold/years） | 格式正确（如"4.8k sold" / "Đã bán 4.8k"） |

### 2.2b 翻译质量 — glossary 预替换验证（新增 0731）
> 0731 起，`translator.py` 在送 Qwen 前用 glossary 直接替换已知中文术语，减少 ~50% prompt token。
> 需确认预替换后的文本 + Qwen 补充翻译 = 完整的正确翻译。
| # | 步骤 | 预期 |
|---|------|------|
| 1 | **vi** 搜索新产品 → 检查标题 | 标题为完整越语，无中文残留 |
| 2 | vi → 检查 factoryFlags | 如"超级工厂"→"Nhà máy siêu cấp"（glossary 值），非 Qwen 直译 |
| 3 | vi → 检查 specs | 规格名+值全越语（之前 max_tokens=2048 导致 JSON 截断，越语最长最易触发） |
| 4 | vi → 查看 `translator.log` | 无 `Qwen returned invalid JSON`；`finish=stop`（非 `length`） |
| 5 | en → 搜索新产品 → 对比翻译 | 所有 Path 3 字段为英文，无中文 |
| 6 | th / id → 搜索新产品 | 同上，各自语言完整翻译 |
| 7 | 查看 `analyze_svc.log` | `[汇总]` 显示 `Qwen✓`（非 `⚠降级`），`displayLang=zh→vi` 等 |
