# 全项目人工测试用例

> 面向测试人员的运行时人工测试用例集。覆盖插件（src/chrome-ext）+ 后端 API（src/api）全部功能线。
> 与 [测试-回归测试计划.md](测试-回归测试计划.md) 的区别：回归计划只查审计弱项；本用例集按用户旅程覆盖全功能。
> 决策日期：2026-08-20

## 范围

| 覆盖 | 不覆盖 |
|------|--------|
| 插件全流程（登录/分析/历史/语言/配额/降级） | 官网展示页（src/web/，未上线） |
| 后端 API（认证/分析/历史/配额/限流/代理） | 会员真实付款链路（用 DB 改 is_paid 代替） |

## 一、测试前置准备

| 项 | 说明 |
|----|------|
| 后端环境 | 本地 venv 起 uvicorn（`--workers 1`，多 worker 会破坏任务状态），或直接测生产 https://sourcely1688.com |
| 测试账号 ×2 | 免费账号（注册送 10 次）；付费账号（DB `user.is_paid=1` 模拟，不真实付款） |
| 测试链接 ×3 | ① 正常供应商 1688 链接 ② 低评分/风险供应商链接 ③ 失效/非 1688 链接 |
| 语言 | zh/en/vi/th 四份 lang/*.json 齐全，后端 glossary.json + display_i18n 可写 |

## 二、用例格式（测试人员填写模板）

```
用例ID | 前置条件 | 操作步骤(编号) | 预期结果 | 实际结果+截图
```

## 三、测试用例集

### T1 登录/账号

| 用例 | 前置 | 步骤 | 预期 |
|------|------|------|------|
| T1.1 插件流登录 | 插件已加载，未登录 | ① 点登录 → ② Google 授权弹窗 → ③ 授权 | 弹窗正常；token 落 chrome.storage.local；自动进分析页；右上角显示已登录 |
| T1.2 语言恢复 | 已登录，default_lang=vi | 重新登录 | 登录后界面语言自动切回 vi（JWT 恢复） |
| T1.3 未登录访问 | 清空 token | 直接打开分析页/历史页 | 受限接口返回 401；页面提示登录，不崩 |
| T1.4 登录失败 | 弹窗内取消授权 | 点登录后取消 | 友好提示「登录取消/失败」，不白屏 |

### T2 核心分析

| 用例 | 前置 | 步骤 | 预期 |
|------|------|------|------|
| T2.1 成功分析 | 免费账号有配额 | 粘贴正常链接 → 分析 | 走完整链路：抓取→判词→显示；结果页出现产品判词 + 供应商验证 + 排名 + 库存 |
| T2.2 二次分析秒出 | T2.1 已完成 | 同链接再分析 | 直接复用 DB raw_json + display_i18n，秒出，不重新抓取 |
| T2.3 缺语言追加翻译 | 链接只有 zh 缓存 | 切到 en 分析 | 命中 raw_json → 跳过 Apify → 追加 en 翻译；之后切 vi/th 同理 |
| T2.4 无效链接 | — | 粘贴非 1688/失效链接 | 明确错误提示（msg_code 有对应翻译），不白屏 |
| T2.5 分析中状态 | — | 点分析后立即观察 | 显示加载占位，无闪烁旧内容 |

### T3 判词正确性

| 用例 | 前置 | 步骤 | 预期 |
|------|------|------|------|
| T3.1 四语言判词 | 正常链接 | 切 zh/en/vi/th 各看一遍判词 | 判词语言纯净（中文版不含英文，英文版不含中文）；翻译通顺无机器腔 |
| T3.2 数字强控 | 含金额/销量数据 | 核对判词中数字 | 数字与原数据一致，货币按语言本地化（¥/$/₫/฿） |
| T3.3 判词档位 | 低评分链接 | 分析后看供应商档位 | 4 档（优选/合格/风险/谨慎）判词与评分匹配 |
| T3.4 排名翻译 | 链接有排名 | 看排名行 | 排名「2026上榜一钻工厂」已翻译为当前语言；🏆 不重复出现 |
| T3.5 中文纯净 | 中文版判词 | DevTools 检查判词文本 | 中文判词不含英文字符（规则 3） |

### T4 历史记录

| 用例 | 前置 | 步骤 | 预期 |
|------|------|------|------|
| T4.1 历史列表 | 有 ≥3 条分析记录 | 打开历史页 | 按时间倒序显示；分页正常 |
| T4.2 打开历史 | 历史页 | 点一条历史 | 进入报告，显示加载占位后出对应语言内容 |
| T4.3 语言切换后打开 | 历史记录是 en 存下，当前切 vi | 切 vi 后点这条历史 | 显示 vi 语言，无「先闪 en 再变」延迟 |
| T4.4 收藏 | 历史页 | 收藏 A → 取消收藏 A | 收藏图标即时变化；刷新后状态保持 |
| T4.5 删除 | 历史页 | 删除 B | 列表立即移除；刷新后不再出现 |
| T4.6 收藏保护 | 收藏 A，配额满 | 触发历史清理 | A 不被清理删除 |

### T5 配额/会员

| 用例 | 前置 | 步骤 | 预期 |
|------|------|------|------|
| T5.1 免费额度 | 免费账号 | 连续分析至额度耗尽 | 额度用尽后提示不可分析，显示剩余次数 |
| T5.2 每日补地板 | 免费账号 | 看剩余次数（free=3/日） | 次日自动补回 3 次 |

| T5.4 连续失败阈值 | — | 同一链接连续失败 ≥3 次 | 出现「明天再试」提示（_fail_count 阈值） |

### T6 降级路径

| 用例 | 前置 | 步骤 | 预期 |

### T7 UI/多语言

## 四、执行顺序

```
T1 登录 → T2 核心分析 → T3 判词正确性（核心链路先通）
→ T4 历史 → T5 配额（数据正确性）
→ T6 降级 → T7 UI/多语言（异常与视觉）
→ T8 安全 → T9 生产环境
```
