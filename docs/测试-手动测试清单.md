# 手动测试清单
> 最后更新：2026-07-24 — V1.3 表精简 + 25 Bug 修复后回归测试

## 测试环境

| 项目 | 值 |
|------|-----|
| 后端地址 | `http://localhost:8008` |
| 启动命令 | `cd src/api && uvicorn main:app --reload --host 0.0.0.0 --port 8008` |
| Apify 免费配额 | **3 次/天** |

---

## 第一轮：核心链路（约消耗 2 次 Apify 配额）

### T1 — 首页加载
1. 打开 `http://localhost:8008`
2. 确认搜索框可见、底部文案显示 **"每日免费 3 次"**（不是 30 次）

### T2 — 搜索 1688 链接（⚠️ 消耗 1 次配额）
1. 粘贴真实 1688 链接：`https://detail.1688.com/offer/1038913113865.html`
2. 确认：骨架屏出现 → 轮询 `/api/analyze/{taskId}` → 结果渲染
3. 确认判词中定金数字为整数（如 25，不是 25.3）

### T3 — 判词一致性
1. 产品判词 — 定金数字正常
2. 工厂判词 — 认证级别标签正确
3. 拿样建议 — 有具体文案

### T4 — 分析完成 → 历史页 → 点记录（DB 加载，不消耗配额）
1. 导航到历史页或访问 `http://localhost:8008/history.html`
2. 点击刚才分析的记录
3. 确认：**秒出结果，不走骨架屏**
4. DevTools Network 确认请求的是 `/api/report/{offerId}`，不是 Apify

### T5 — 历史页再次点同一条（确认不调 Apify）
1. 再次点击同一条记录
2. DevTools Network **无任何 Apify 请求**

### T6 — 刷新 report 页
1. 在 report 页按 F5
2. sessionStorage 缓存恢复，秒出结果

---

## 第二轮：边界 + 异常（不消耗额外配额）

### T7 — 未登录搜索（无痕窗口）
1. 开无痕窗口 → 访问 `http://localhost:8008`
2. 搜索 1688 链接（⚠️ 消耗 1 次配额）
3. 确认：正常分析、结果页无"保存"按钮

### T8 — 搜索失败 → 按钮恢复
1. 断网 → 点击搜索
2. 确认：骨架屏消失、搜索按钮恢复可用、错误提示出现

### T9 — 分析失败后刷新不重复调 Apify
1. 访问 `http://localhost:8008/report.html?offerId=0000000000000` 触发失败
2. F5 刷新
3. 确认：不重复调 Apify、URL 里 offerId 已被清除、按钮可用

### T10 — Toast 上限
1. 快速连点搜索按钮 6 次
2. 确认：最多 5 个 Toast，不叠加溢出

### T11 — 分享卡片
1. 分析结果页点分享
2. 确认：卡片生成正常，关闭后再生成 blob URL 不泄漏

### T12 — 历史删除
1. 历史页删除一条记录
2. 确认：DOM 消失、计数更新、刷新后确认 DB 已删除

### T13 — 保存报告
1. 登录 → 分析完成 → 点保存
2. 确认：返回成功、历史页有这条记录
3. DevTools Network 确认 POST 返回 200

## 建议执行顺序（节省配额）

```
先不登录：T1 → T2 → T3 → T8 → T9 → T10
再登录：  T4 → T5 → T6 → T11 → T12 → T13
最后：    T7（无痕窗口，消耗最后 1 次配额）
```
