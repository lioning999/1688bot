## 前端 `src/web/`

```
src/web/
├── index.html            # 首页（搜索入口）
├── report.html           # 报告页（分析结果展示）
├── history.html          # 历史记录页（已保存报告列表）
├── help.html             # 帮助/FAQ 页
├── favicon.ico           # 网站图标
│
├── lang/i18n/            # 多语言翻译（静态壳翻译，前端 i18n 系统加载）
│   ├── en.json           #   英文
│   ├── vi.json           #   越南语
│   └── th.json           #   泰语
│
├── samples/              # 静态样例数据（demo 页面，不调 Apify）
│   └── {name}/
│       ├── data.json     #   mapped 数据
│       └── {lang}.json   #   display JSON（按语言）
│
└── static/               # 静态资源
    ├── css/
    │   ├── common.css    #   全局 CSS 变量 + 通用样式
    │   └── style.css     #   report 页专属样式（进度条、报告卡片等）
    ├── img/              #   图片资源
    ├── js/
    │   ├── api/
    │   │   └── core.js   #   API 统一入口：所有 fetch 调用、authHeaders、统一错误处理
    │   ├── pages/
    │   │   ├── report.js #   报告页逻辑：搜索、进度、轮询、渲染、保存
    │   │   ├── index.js  #   首页逻辑
    │   │   └── history.js#   历史页逻辑
    │   └── utils/
    │       ├── i18n.js   #   多语言引擎：语言检测、JSON 加载、DOM 遍历替换
    │       ├── components.js # 通用组件：Nav、Toast、checkAuth
    │       └── share.js  #   图片分享功能
    └── fonts/            # 字体文件
```

## 后端 `src/api/`

```
src/api/
├── .env.example          # 环境变量模板（不含密钥，可提交 Git）
├── requirements.txt      # Python 依赖清单
├── main.py               # 应用入口：FastAPI 实例、中间件注册、路由挂载、lifespan
├── config.py             # 配置中心：从 .env 读所有配置，Config.XXX 全局引用
├── database.py           # 数据库连接池：aiomysql，5-20 连接，DictCursor
├── middleware.py          # JWT 认证中间件：/api/* 拦截，校验 Bearer token
├── CLAUDE.md             # 后端 AI 护栏（写后端代码前必读）
│
├── adapters/             # 外部 API 封装层（一个服务一个文件，不含业务逻辑）
│   ├── apify_adapter.py  #   Apify 1688 Scraper：多 token 轮换、超时降级
│   └── google_auth.py    #   Google OAuth 2.0：授权 URL 生成、code 换 id_token
│
├── routes/               # 路由层：Pydantic 参数校验 + 调用 service + 标准响应
│   ├── analyze.py        #   POST /api/analyze（启动分析）、GET /api/analyze/{task_id}（轮询）
│   ├── auth.py           #   Google 登录回调、JWT 签发
│   ├── history.py        #   历史记录 CRUD、GET /api/report/{offer_id}（DB 读报告）
│   └── proxy.py          #   图片代理（防 1688 防盗链）
│
├── services/             # 业务编排层：串联 adapter + domain + repository
│   ├── analyze_svc.py    #   分析流水线：缓存→Apify→mapper→判词→display→翻译→入库
│   └── auth_svc.py       #   Google 登录：验证 id_token → upsert user → 签发 JWT
│
├── domain/               # 纯逻辑层（零外部依赖，不调 DB/HTTP/环境变量）
│   ├── cache.py          #   内存缓存：offer_id → mapped, TTL 30min, LRU 500 条
│   ├── display_builder.py#   Display JSON 构建器：3 路处理（Path1 英文/Path2 字典/Path3 中文）
│   ├── product_mapper.py #   数据清洗：Apify 原始 21 字段 → 标准化 29 mapped 字段
│   ├── rate_limiter.py   #   全局限流：滑动窗口 30 次/分钟
│   ├── translator.py     #   Qwen 翻译：display JSON 中 Path 3 中文字段翻译为 en/vi/th/id
│   ├── translator_prompts.json  # 翻译 prompt 模板
│   ├── urls.py           #   1688 URL 解析：extract_offer_id / is_valid_1688_url
│   ├── verdict_engine.py #   判词引擎：L1+L2+L3 三层规则，产品/工厂/拿样三类判词
│   └── verdict_templates.json  # 判词文案模板
│
├── repositories/         # 数据库操作层（每表一个文件，自管连接生命周期）
│   ├── analysis_repo.py  #   analysis 表：CRUD、upsert、display_i18n 读写
│   └── user_repo.py      #   users 表：upsert、按 Google ID 查
│
├── utils/                # 纯工具（不依赖 services/routes）
│   ├── exceptions.py     #   异常体系：4 种 AppError，全局处理器自动转 JSON
│   ├── jwt.py            #   JWT 工具：HS256 签发/校验
│   └── logger.py         #   日志：文件轮转 + 控制台双输出，email/token 脱敏
│
├── db/                   # 数据库相关文件
│   ├── schema.sql        #   建表 SQL（users + analysis）
│   └── client_secret_*.json  # Google OAuth client secret（不提交 Git）
│
└── logs/                 # 运行日志（不提交 Git）
```
