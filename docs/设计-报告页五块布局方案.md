## 二、页面结构总览（从上到下）

| 序号 | 模块 | 内容 | 用户看到什么 |
|------|------|------|------------|
| — | **顶部导航** | Logo + 语言切换 + 登录 | 知道自己在哪里，能切换语言 |
| ① | **商品确认** | 标题 + 价格 + 起订量 + 销量 | 核对是不是自己搜的那款 |
| ② | **综合结论（色块）** | 判词 + 3个核心指标 + 一句话理由 | **3秒内知道能不能拿** |
| ③ | **利润分析** | 阶梯价 + 参考零售价 + 用户输入 + 利润结果 | 知道赚不赚钱、能赚多少 |
| ④ | **供应商实力** | 公司名 + 经营模式 + 年限 + 注册资本 + 资质标签 | 知道工厂规模、实力如何 |
| ⑤ | **品质与认证** | SGS + ISO + 质检报告 + 验厂详情 | 知道品质有没有保障 |
| ⑥ | **市场表现** | 销量 + 好评率 + 复购率 + 品类排名 | 知道市场验证过没有 |
| ⑦ | **风险提示** | 当前风险 + 注意事项 + 历史记录 | 知道有什么坑、怎么避 |
| ⑧ | **拿样与发货** | 总费用 + 4步流程 + 服务承诺 + 预估时效 | 知道怎么操作、有什么保障 |
| ⑨ | **行动按钮** | 拿样咨询 + 对比其他工厂 | 点击即达下一步 |

## 三、关键设计要点

| 设计要点 | 说明 |
|---------|------|
| **先结论后论据** | 综合结论在顶部，用户3秒内看到"能不能拿" |
| **每个维度独立成块** | 每个维度有标题、有内容、有问号解释 |
| **问号解释每个术语** | "什么是超级工厂？""什么是SGS认证？"点击即看 |
| **利润让用户自己填** | 提供行业参考倍率，用户填售价和运费，系统算利润 |
| **拿样流程可视化** | 四步流程用箭头串联，费用透明 |
| **服务承诺打勾展示** | 7天包换/48小时发货/品质不符包赔，一目了然 |
| **多语言支持** | 显示当前国家的语言（越南语/印尼语/马来语/泰语/英语） |

## 五、后端影响评估

**状态：无需后端改动。**

`display_builder.py` 的 `build_display()` 已返回所有需要的字段（title, price, trustBar, badges, verdictProduct, verdictFactory, verdictSample, factory, specs, sales, skus, priceTiers）。利润分析块的计算逻辑在前端完成（用户输入售价 × 阶梯价），后端只提供阶梯价数据。

唯一的新增需求（未来 V2）：
- 品类参考零售价（需要对接 Shopee/Lazada API 或预置品类倍率表）
- 风险提示规则引擎（目前 verdict_engine 不输出风险维度）
