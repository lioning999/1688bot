## 一、组件定义

| 组件 | 定位 | 生命周期 | 位置 | 文件 |
|------|------|---------|------|------|
| **Toast** | 瞬态通知（操作结果） | 4-6s 自动消失 | `fixed; bottom:24px; center` | `components.js` |
| **Alert Banner** | 重要消息（阻塞/警告） | 手动点 × 关闭 | `sticky; top:0; z-index:999` | `components.js` |
| **内联错误** | 结果区内的错误 | 不消失（随内容刷新） | 替换 `#result` 区域 | 各页面 JS |

---

## 二、决策树

```
消息严重吗？
  ├─ 成功 / 纯信息   → Toast（4s 自动消失）
  ├─ 警告 / 可恢复错误 → Alert Banner（用户手动关）
  └─ 结果区错误        → 内联替换结果区内容（不消失）
```

**判断标准（一句话）：** 用户是不是必须看到这条消息才能继续操作？是 → Alert/内联。否 → Toast。

## 三、当前消息归类

### Toast（瞬态）

| 消息 | 触发场景 |
|------|---------|
| 保存成功！可在历史记录中查看 | 保存分析结果 |
| 链接已复制！可粘贴到微信/WhatsApp | 点击复制链接 |
| 已恢复之前的数据 — 每日免费 30 次 | 从 sessionStorage 恢复 |
| 图片正在上传，请稍候 | 分享时图片还未上传完 |

### Alert Banner（重要，手动关）

| 消息 | 触发场景 |
|------|---------|
| 今日免费分析次数已用完，请明天再试 | 我们的 daily quota 耗尽 |
| Apify 服务暂时不可用，请稍后再试 | Apify API 配额耗尽或异常 |
| 图片生成失败，请重试。如持续失败请截图分享 | html2canvas 渲染异常 |

### 内联错误（不消失）

| 消息 | 触发场景 |
|------|---------|
| 该链接可能已下架，请检查后重试 | 商品不存在 |
| 获取失败，请稍后重试。如持续失败请联系客服 | 分析超时等非预期错误 |

## 四、CSS 规格

### Toast
```
position: fixed; bottom: 24px; left: 50%; transform: translateX(-50%);
max-width: 480px; padding: 12px 16px;
background: var(--paper); border: 1px solid var(--line);
border-radius: 8px; box-shadow: 0 4px 16px rgba(0,0,0,.12);
display: flex; align-items: center; gap: 8px;
```

### Alert Banner
```
position: sticky; top: 0; z-index: 999;
width: 100%; padding: 12px 16px;
display: flex; align-items: center; gap: 10px;
左侧 3px 色条（warning=黄色, error=红色, info=蓝色）
右侧 × 关闭按钮（min 44x44px 触控区域）
```

### 内联错误
```
居中：icon(48px) + 标题 + 描述 + 可选操作按钮
替换 #result 区域内容
```
