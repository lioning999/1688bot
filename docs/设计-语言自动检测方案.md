# 语言自动检测方案

> 目录索引：[[docs/README.md]] · [[docs/项目架构宪法.md]]
> 生命周期：**草案** · 创建：2026-07-25

---

## 目标

用户打开网站 → 自动显示他的浏览器语言。不用手动切换。

---

## 支持语言

| 代码 | 语言 | 优先级 |
|------|------|--------|
| `en` | English | 默认（fallback） |
| `zh` | 中文 | — |
| `vi` | Tiếng Việt | — |
| `th` | ภาษาไทย | — |
| `id` | Bahasa Indonesia | — |

---

## 检测逻辑

```
页面加载
  ↓
读 navigator.language → "vi-VN" / "th-TH" / "id-ID" / "zh-CN" / other
  ↓
取前 2 位 → "vi" / "th" / "id" / "zh" / "en"
  ↓
匹配支持的语言列表 → 命中 → 加载对应翻译
                     → 未命中 → fallback "en"
  ↓
检查 localStorage("sourcely_lang") → 用户手动选过 → 以手动选择为准
```

**优先级：** 用户手动选择 > 浏览器语言 > 默认英文

---

## 翻译文件结构

每个语言一个 JSON 文件，放 `src/web/static/i18n/`：

```
static/i18n/
  en.json    # 英文（源语言，其他语言以此为基准）
  zh.json    # 中文
  vi.json    # 越南语
  th.json    # 泰语
  id.json    # 印尼语
```

### JSON 格式

```json
{
  "nav": {
    "home": "Home",
    "history": "History"
  },
  "index": {
    "hero_title": "Source from 1688 Factories Directly",
    "search_placeholder": "Paste 1688 product link...",
    "search_btn": "Analyze"
  },
  "report": {
    "verdict_title": "Verdict",
    "factory_tab": "Factory",
    "sample_tab": "Sample"
  },
  "common": {
    "loading": "Loading...",
    "error_network": "Network error, please try again",
    "login": "Sign in with Google",
    "logout": "Sign out"
  }
}
```

### 命名规则

```
{页面}.{区域}_{元素}    # 如 report.verdict_title, index.hero_title
common.{元素}           # 跨页面通用的放 common
```

## 前端实现

### V1 实现方式：模板替换（0.5 天）

每页 HTML 元素加 `data-i18n` 属性：

```html
<h1 data-i18n="index.hero_title">Source from 1688 Factories Directly</h1>
```

JS 加载翻译文件后，遍历 `[data-i18n]` 替换：

```js
// i18n.js — 语言检测 + 翻译加载
var I18N = (function () {
  var _current = 'en';
  var _dict = {};

  function init() {
    var saved = localStorage.getItem('sourcely_lang');
    if (saved) return load(saved);

    var lang = (navigator.language || 'en').slice(0, 2);
    var supported = ['zh', 'en', 'vi', 'th', 'id'];
    load(supported.includes(lang) ? lang : 'en');
  }

  function load(lang) {
    fetch('/static/i18n/' + lang + '.json')
      .then(function (r) { return r.json(); })
      .then(function (dict) {
        _dict = dict;
        _current = lang;
        apply();
        // 同步 lang switcher 的选中值
        var sel = document.getElementById('langSwitcher');
        if (sel) sel.value = lang;
      });
  }

  function apply() {
    var els = document.querySelectorAll('[data-i18n]');
    els.forEach(function (el) {
      var key = el.getAttribute('data-i18n');
      var val = getNested(_dict, key);
      if (val) el.textContent = val;
    });
    // placeholder 类属性
    var ph = document.querySelectorAll('[data-i18n-placeholder]');
    ph.forEach(function (el) {
      var key = el.getAttribute('data-i18n-placeholder');
      var val = getNested(_dict, key);
      if (val) el.placeholder = val;
    });
  }

  function setLang(lang) {
    localStorage.setItem('sourcely_lang', lang);
    load(lang);
  }

  function getNested(obj, path) {
    return path.split('.').reduce(function (o, k) { return o && o[k]; }, obj);
  }

  return { init: init, setLang: setLang };
})();
```

### components.js 改动

`renderNav()` 中的语言切换器绑定事件：

```js
var langSwitcher = document.getElementById('langSwitcher');
if (langSwitcher) {
  langSwitcher.addEventListener('change', function () {
    I18N.setLang(this.value);
  });
}
```

### 每页引入

```html
<script src="static/js/i18n.js"></script>
<script>
  I18N.init();
  renderNav(null);
  renderFooter();
</script>
```

## V1 范围 vs V2 扩展

| | V1 | V2 |
|------|-----|------|
| 覆盖范围 | 首页 + report + 历史 + nav/footer | 静态页面（privacy/terms/about/flow） |
| 翻译方式 | JSON 文件，前端替换 | 考虑后端模板或 CDN 静态文件 |
| 翻译维护 | 手动翻译 | 翻译管理平台或 AI 辅助 |
| 图片文字 | 不改 | 按语言替换图片 |

## 注意事项

1. **搜索引擎：** 不同语言的页面 URL 相同，Google 可能只索引一种语言。V2 考虑 `sourcely.cc/vi/` 子路径。
2. **CSS 方向：** 英语/越南语/印尼语/泰语都是 LTR，不需要 RTL 适配。
3. **字体加载：** Google Fonts 已加载 Noto Sans SC（中文），其他语言用系统字体 fallback。
