## 一、阿里云 ECS 购买 + 初始化（15 min）

### 1.1 选配

| 配置项 | 推荐值 | 月费（参考） |
|--------|--------|-------------|
| 实例规格 | ecs.c6.large（2C4G）或 ecs.e-c1m2.large（2C4G 共享型） | ~¥120-200 |
| 系统盘 | 40G ESSD Entry | ~¥20 |
| 带宽 | 按流量计费，5Mbps 峰值 | ~¥0.8/GB |
| 地域 | 新加坡（东南亚用户延迟低）或 香港 | — |
| 操作系统 | Ubuntu 22.04 LTS | — |

**为什么选新加坡**：目标用户是越南/印尼/泰国，新加坡到东南亚延迟 <50ms。香港到东南亚延迟也低，但对内地访问更友好。

### 1.2 安全组规则（ECS 控制台 → 安全组）

| 方向 | 端口 | 来源 | 用途 |
|------|------|------|------|
| 入方向 | 22 | 你的 IP（或 0.0.0.0/0） | SSH |
| 入方向 | 80 | 0.0.0.0/0 | HTTP（Let's Encrypt 验证 + 用户访问） |
| 入方向 | 443 | 0.0.0.0/0 | HTTPS |
| 入方向 | 3306 | 127.0.0.1 | MySQL（仅本地） |

**禁止开放 3306 到公网**。MySQL 只允许本地连接。


## 七、systemd 服务（保活 + 开机自启）

```bash
cat > /etc/systemd/system/sourcely.service << 'EOF'
[Unit]
Description=Sourcely API Server
After=network.target mysql.service
Wants=mysql.service

[Service]
User=www-data
Group=www-data
WorkingDirectory=/opt/sourcely/src/api
Environment="PYTHONIOENCODING=utf-8"
Environment="PATH=/opt/sourcely/src/api/venv/bin:/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin"
ExecStart=/opt/sourcely/src/api/venv/bin/uvicorn main:app --host 127.0.0.1 --port 8008 --workers 4
Restart=always
RestartSec=5
StandardOutput=append:/opt/sourcely/src/api/logs/stdout.log
StandardError=append:/opt/sourcely/src/api/logs/stderr.log

[Install]
WantedBy=multi-user.target
EOF

# 创建日志目录 + 设置权限
mkdir -p /opt/sourcely/src/api/logs
chown -R www-data:www-data /opt/sourcely

# 启动
systemctl daemon-reload
systemctl enable sourcely
systemctl start sourcely

# 检查
systemctl status sourcely
curl http://127.0.0.1:8008/health
```

验证：
```bash
systemctl is-active sourcely   # → active
systemctl is-enabled sourcely  # → enabled
curl -s http://127.0.0.1:8008/health
# → {"status":"ok","database":"connected"}

# 确认 workers 数量（4 个 python 进程）
ps aux | grep uvicorn | grep -v grep | wc -l
# → 5 (1 master + 4 workers)

# 确认以 www-data 用户运行
ps aux | grep uvicorn | grep -v grep | head -1 | awk '{print $1}'
# → www-data
```

## 八、Nginx 配置 + HTTPS（10 min）

```bash
cat > /etc/nginx/sites-available/sourcely << 'EOF'
# 80 端口 — HTTP（certbot 验证用，永久重定向到 HTTPS）
server {
    listen 80;
    server_name sourcely1688.com www.sourcely1688.com;
    return 301 https://$host$request_uri;
}

# 443 端口 — HTTPS
server {
    listen 443 ssl http2;
    server_name sourcely1688.com www.sourcely1688.com;

    # SSL 证书（certbot 自动填充）
    ssl_certificate     /etc/letsencrypt/live/sourcely1688.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/sourcely1688.com/privkey.pem;

    # 安全头
    add_header Strict-Transport-Security "max-age=63072000" always;
    add_header X-Content-Type-Options nosniff;
    add_header X-Frame-Options SAMEORIGIN;

    # Gzip（和 FastAPI GZipMiddleware 互补——Nginx 压静态资源，FastAPI 压 API 响应）
    gzip on;
    gzip_types text/css application/javascript image/svg+xml;
    gzip_min_length 1000;

    # 日志
    access_log /var/log/nginx/sourcely_access.log;
    error_log  /var/log/nginx/sourcely_error.log;

    # 客户端最大 body（防止大 payload 攻击）
    client_max_body_size 10m;

    # 图片代理（长连接，不缓冲）
    location /api/proxy/image {
        proxy_pass http://127.0.0.1:8008;
        proxy_buffering off;
        proxy_read_timeout 30s;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }

    # 主应用
    location / {
        proxy_pass http://127.0.0.1:8008;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;  # Apify 最长等待 90s
    }
}
EOF

# 启用站点
ln -s /etc/nginx/sites-available/sourcely /etc/nginx/sites-enabled/
rm -f /etc/nginx/sites-enabled/default
nginx -t

# 先 HTTP 模式启动，让 certbot 能验证域名
systemctl reload nginx
```

验证（SSL 申请前）：
```bash
nginx -t                          # → syntax is ok / test is successful
systemctl is-active nginx         # → active
# 从外网验证域名解析 + 80 端口可达（在本地机器执行）
curl -sI http://sourcely1688.com/ | head -1
# → HTTP/1.1 301 Moved Permanently (Nginx 重定向到 HTTPS)
```

### 获取 SSL 证书

```bash
certbot --nginx -d sourcely1688.com -d www.sourcely1688.com --non-interactive --agree-tos -m <你的邮箱>

# 验证自动续期
certbot renew --dry-run
```

验证 SSL 证书：
```bash
# 证书有效期
openssl s_client -connect sourcely1688.com:443 -servername sourcely1688.com </dev/null 2>/dev/null \
  | openssl x509 -noout -dates
# → notBefore=... / notAfter=...（90 天有效期）

# 证书签发者
openssl s_client -connect sourcely1688.com:443 -servername sourcely1688.com </dev/null 2>/dev/null \
  | openssl x509 -noout -issuer
# → issuer=... Let's Encrypt ...

# SSL Labs 评分（可选）
curl -sI https://sourcely1688.com/ | head -5
# → HTTP/2 200
# → strict-transport-security: max-age=63072000
```

## 十、Google OAuth Console 配置（⭐ 必须）

1. 打开 https://console.cloud.google.com/apis/credentials
2. 找到你的 OAuth 2.0 Client ID → 编辑
3. **Authorized redirect URIs** 添加：
   ```
   https://sourcely1688.com/google-callback
   ```
4. 保存。**没加这条 → 所有 Google 登录报 `redirect_uri_mismatch`。**
