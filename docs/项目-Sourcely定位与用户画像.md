## 一、Sourcely 是什么

**帮东南亚卖家把已经看中的品、从 1688 安全便宜地拿回来。**

| 不是 | 是 |
|------|-----|
| ❌ 选品参谋 — 不告诉你什么品赚钱 | ✅ 采购管家 — 帮你看中的品落地 |
| ❌ 1688 数据翻译器 | ✅ 工厂可信度验证 + 拿样验货 + 国际物流 |
| ❌ "这个品能赚多少" | ✅ "这个品到岸成本多少，你自己算利润" |

### 用户路径

```
用户看到本地某品卖得好 → 本地批发价太贵 → 想来 1688 找源头
→ 不懂中文、怕被坑、搞不定物流 → 找到 Sourcely
→ 我们帮他：验证工厂 → 低成本拿样 → 验货拍照 → 国际发货
```

**选品是用户的事，验证和落地是我们的事。** 我们如果知道哪个品一定赚钱，早自己干了——不替用户做选品决策，只帮他把决策落地。

### 一句话差异化

> 别的代购说"你发链接我帮你买"，Sourcely 说"我先告诉你这个工厂能不能合作，再帮你买，买完帮你验。"

Sourcely 卖的不是代购，是**降低试错成本**。1688 上一个手机壳有 5000 家店，海外卖家不知道哪家靠谱、不敢下单。替他验证、帮他拿样、验完再发国际——试错成本从"一批货砸手里"降到"¥12 拿两件样品看看"。

## 二、客户是谁

**东南亚电商卖家**，在 Shopee / TikTok Shop / Lazada 上开店。他们已经知道要卖什么——在本地市场看到了、验证了需求——缺的是一个安全便宜的 1688 进货通道。

### 典型用户画像

**卖家 A — 小规模试水型**
- 越南 · Shopee · 配件/百货 · 月销 ~200 单
- 核心恐惧：差评扣分（Shopee 对差评极其敏感）
- 价格敏感度：高
- 一句话："我先拿 2-3 个样品试试，质量 OK 再小批量。别让我一次订 500 件。"

**卖家 B — 中等规模增长型**
- 印尼 · TikTok Shop · 美妆/个护 · 月销 ~800 单
- 核心恐惧：爆单断货（TikTok 算法推起来就 3 天的事）
- 价格敏感度：中（宁愿多花 20% 确保供应链稳定）
- 一句话："断货比贵更致命。"

**卖家 C — 稳定经营品质型**
- 泰国 · Lazada · 家居/饰品 · 月销 ~300 单
- 核心恐惧：货不对板（之前被代购坑过，图片 A 级品、发货 B 级品）
- 价格敏感度：中低（验货不是成本，是保险）
- 一句话："没验货我不下单。照片确认了再发国际。"

## 三、inspect 验货报告页的角色

**转化工具。** 用户从首页搜了 1688 链接 → 得到工厂分析 + 成本结构 → 产生信任 → 想要拿样 → 咨询 WhatsApp。

```
首页搜索 → 分析结果 → inspect 验货报告页 → 信任建立 → 拿样决策 → WhatsApp 咨询
```

### inspect 页面信息架构（按决策顺序）

| 层次 | 回答什么问题 | 内容 |
|------|------------|------|
| **① 这是什么品** | 我搜的是不是这个？ | 商品图、标题、1688 价格、起订量 |
| **② 工厂靠不靠谱** | 会不会被坑？ | 认证、年限、销量、产业带 |
| **③ 成本多少** | 到岸多少钱？ | 阶梯价格 + 国内运费 + 国际运费 + 服务费 |
| **④ 怎么拿样** | 流程是什么？ | 付定金 → 验货拍照 → 付尾款 → 国际发货 |
| **⑤ 验货长什么样** | 我能看到什么？ | 验货清单 + 实拍样例（正面/侧面/标签/瑕疵/包装/SKU） |

**核心原则：我们帮你算成本，利润你自己算。** 利润计算器降级为成本计算器——不给"毛利率 73%"这样的结论，只给"到岸成本 ¥4.10/件"，用户填入自己的当地售价后自行判断。

## 四、竞品位置

| 竞品 | 做法 | Sourcely 的优势 |
|------|------|----------------|
| 个人代购（微信群/Facebook Group） | "你发链接我帮你买" | 多了"工厂判断"能力，不是纯跑腿 |
| 1688 跨境专供频道 | 1688 官方跨境专区，有英文 | 多了第三方中立判断 + 验货环节 |
| 速卖通 AliExpress | 面向海外零售 | 价格比速卖通低很多，是"源头价" |
| 自己翻 1688 + Chrome 翻译 | 手动找货 | 省 2 小时 + 工厂可信度分析 + 验货兜底 |

**最直接的竞争对手不是某个产品，而是"自己翻 1688"这个行为 + "找个人代购"这个习惯。** Sourcely 赢在"验证力"和"验货兜底"，不是价格。

## 五、信任建设策略

信任是转化漏斗最窄的地方。建设方式——**能证明的证明，不能证明的不承诺。**

| 能做的 | 不能做的 |
|--------|----------|
| ✅ 首页放验货实拍案例（真实做过的品） | ❌ 保证某品一定赚钱 |
| ✅ TUV 等认证加外部链接，用户自行核实 | ❌ 声称我们抓取了 1688 认证数据 |
| ✅ 验货清单配样例照片 | ❌ 承诺"和照片 100% 一样" |
| ✅ 真实买家反馈截图（退款/验货案例） | ❌ 编造评价 |
