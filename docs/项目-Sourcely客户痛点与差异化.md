## 一、客户是谁

**东南亚电商卖家**（越南/印尼/泰国/马来），在 Shopee / TikTok Shop / Lazada 开店。

他们已经在本地市场验证了需求——看到一个品卖得好，想从 1688 拿货，但被三个问题卡住。

---

## 二、客户痛点（3 个，按优先级）

### 痛点 1：看不懂中文，不知道工厂靠不靠谱

| | 描述 |
|------|------|
| **现状** | 用 Chrome 翻译翻 1688 店铺页面，翻译出来乱七八糟，"实力商家"翻成 "Strong merchant"，不知道到底代表什么 |
| **后果** | 花 2-3 小时翻一个店铺，最后还是不敢下单——怕工厂是假的、怕质量不行 |
| **竞品谁能解决** | ❌ 没有人。AiPrice 帮你找同款但不判断工厂；代购只负责下单不负责分析 |
| **我们怎么做** | 8 维度工厂分析 + 判词结论（推荐/谨慎/避开）。用户 10 秒知道这厂能不能合作 |

### 痛点 2：怕付了钱货不对板

| | 描述 |
|------|------|
| **现状** | 直接打款给未知工厂 → 要么不敢下单、要么下单后收到货发现和图片不符 → 退不了 |
| **后果** | 试错成本不是 2 件样品钱，是一批货砸手里 + 店铺差评扣分（Shopee 一个 1 星能毁半个月流量） |
| **竞品谁能解决** | ❌ 没有人。代购不负责验货——他帮你下单、转发你的地址，货对不对你自己承担 |
| **我们怎么做** | 先付小额定金 → 我们收货验货拍照 → 你确认满意 → 再付尾款发国际。不满意退定金 |

### 痛点 3：搞不定中国到本国的物流

| | 描述 |
|------|------|
| **现状** | 1688 不直发东南亚，卖家要找转运、填报关、算运费——全是中文界面 |
| **后果** | 要么放弃、要么找不靠谱的转运被坑 |
| **竞品谁能解决** | ⚠️ 代购能做但不专业——他帮你寄但不帮你优化路线和成本 |
| **我们怎么做** | 打包 + 国际物流一条龙。卖家只需要收货，中间环节我们全管 |

## 三、我们的卖点（3 个，对应 3 个痛点）

| 卖点 | 一句话 | 对应痛点 |
|------|--------|----------|
| **工厂可信度判断** | 8 维度分析 + 判词，10 秒知道这厂能不能合作 | 痛点 1 |
| **验货兜底** | 先验货后付尾款，不满意退定金——试错成本降到 ¥12 | 痛点 2 |
| **全流程托管** | 下单→收货→验货→打包→国际物流，卖家只管收货 | 痛点 3 |

## 四、差异化（和谁比、强在哪）

### 4.1 和直接竞品比

| 竞品 | 他们做什么 | 我们的差异化 |
|------|-----------|-------------|
| **AiPrice（爱价格）** | 浏览器插件：以图搜货、比价、抠图——找同款效率工具 | 他们解决"找"，我们解决"判断"。用户先用 AiPrice 找到同款，再用 Sourcely 判断能不能拿 |
| **GP Sourcing** | 社群代购：Facebook 群组接单、WhatsApp 沟通、赚代购费 | 他们有沟通，我们有分析+验货。用户找他们下单，出了质量问题没人负责 |
| **1688 Wholesale Analyzer** | Apify 平台：抓取 1688 数据给开发者用 | 他们给数据，我们给结论+服务闭环。他们的用户是技术型卖家，我们的用户是普通小卖家 |
| **个人代购** | "你发链接我帮你买" | 我们多了工厂判断+验货+不满意退款。代购是跑腿的，我们是管家 |

### 4.2 核心护城河

| 护城河 | 为什么别人难复制 |
|--------|-----------------|
| **验货实拍** | 需要中国本地团队——收货、拆包、拍照、检查。纯线上竞品做不了 |
| **工厂分析引擎** | 8 维度规则引擎 + 产业带知识——台州眼镜、澄海玩具这些产地知识需要深耕 |
| **服务闭环** | 分析→拿样→验货→物流，一条链路打通。竞品只做其中一段 |

### 4.3 一句话差异化

> **AiPrice 帮你找到货，Sourcely 帮你相信这个货。**
>
> 别的代购说"你发链接我帮你买"，Sourcely 说"我先告诉你这厂能不能合作，再帮你买，买了帮你验。"

## 五、盈利方式

| 收入来源 | 模式 | 说明 |
|----------|------|------|
| **样品服务费** | 按次收费，$10/次 | 含代下单 + 验货拍照 + 打包 + 送物流仓。用户为"省心"付费，不是为"信息"付费 |
| **大货服务费** | 按订单金额百分比 | 验货确认后用户批量采购时收取，比样品服务费高 |
| **国际物流差价** | 物流服务加价 | 打包 + 国际物流一条龙，赚取物流差价 |

**不做的盈利方式：**
- ❌ 订阅制 — 小卖家不会按月付费
- ❌ 联盟佣金 — 1688 不支持跨境联盟返佣
- ❌ 卖数据 — 数据不值钱，值钱的是"判断"和"服务"

**核心逻辑：免费分析引流 → 拿样服务变现。** 分析报告本身不收费——用户搜了 1688 链接就能看工厂分析。转化点在拿样——"¥12 试一个品，我帮你验。"
