# Sourcely — 1688 Supplier Due Diligence

> [Tiếng Việt](README.vi.md) · [ภาษาไทย](README.th.md)

Open any product page on **1688.com**, click the Sourcely icon, and get an instant background check on the supplier before you place an order.

## Features

- **Product score (out of 18)** — price, MOQ, sales volume, stock, specifications, and parameters, each verified against real data.
- **Supplier score (out of 9)** — certifications, years in business, company scale, and shipping location.
- **Clear 4-level verdict** — 🟢 safe to cooperate · 🟡 be cautious · 🔴 better to avoid · ⬜ insufficient data.
- **Compare up to 3 products** side by side — price, MOQ, scores, sales, stock, and supplier identity.
- **Native-language reports** — Vietnamese, Thai, English, Chinese.
- **History + favorites** — past checks are saved; pin important suppliers with ⭐ so they never get auto-cleared.
- **One-click Google login** — no registration.

## Installation (Chrome)

> The extension is in development, so it's installed manually in "Developer mode". Follow these 4 steps:

### Step 1 — Download

Download and unzip the latest release zip from the **Releases** page on this repo.

### Step 2 — Open the extensions page

Type `chrome://extensions` in the address bar and press **Enter**.

### Step 3 — Enable Developer mode

Toggle **Developer mode** (top-right corner of the page).

### Step 4 — Load the extension

1. Click **Load unpacked**.
2. Select the **unzipped folder** (the one containing `manifest.json`).
3. The Sourcely icon appears in the browser toolbar — pin it if you like.

## How to use

1. Go to a product page on `1688.com`.
2. Click the **Sourcely** icon in the toolbar (or click it with the product page open).
3. Read the supplier report — scores, verdict, and comparison.
4. Log in with Google when prompted.

## FAQ

**Why do I need Developer mode?**
Because the extension isn't published to the Chrome Web Store yet. Once it's approved there, you'll install it with one click — no Developer mode needed.

**Is there a charge?**
The service offers a free quota for daily use, and paid plans with higher limits. Details are shown inside the extension after login.

**Something doesn't work / I have feedback?**
Open an issue on this repo, or contact us via the support link inside the extension.
