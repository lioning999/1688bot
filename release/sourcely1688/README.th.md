# Sourcely — ตรวจสอบผู้ขายสินค้า 1688

> [English](README.md) · [Tiếng Việt](README.vi.md)

เปิดหน้ารายการสินค้าใด ๆ บน **1688.com** คลิกไอคอน Sourcely แล้วรับผลตรวจสอบผู้ขายทันทีก่อนสั่งซื้อ

## คุณสมบัติ

- **คะแนนสินค้า (เต็ม 18)** — ราคา, จำนวนสั่งขั้นต่ำ (MOQ), ยอดขาย, สต็อก, สเปก และพารามิเตอร์ — ตรวจสอบจากข้อมูลจริงทุกข้อ
- **คะแนนผู้ขาย (เต็ม 9)** — ใบรับรอง, จำนวนปีดำเนินกิจการ, ขนาดบริษัท และที่ตั้งจัดส่ง
- **ผลสรุป 4 ระดับชัดเจน** — 🟢 ปลอดภัยร่วมงาน · 🟡 ใช้ความระมัดระวัง · 🔴 ควรหลีกเลี่ยง · ⬜ ข้อมูลไม่เพียงพอ
- **เปรียบเทียบสินค้าได้สูงสุด 3 รายการ** ควบคู่กัน — ราคา, MOQ, คะแนน, ยอดขาย, สต็อก และสถานะผู้ขาย
- **รายงานเป็นภาษาท้องถิ่น** — ไทย, เวียดนาม, อังกฤษ, จีน
- **ประวัติ + รายการโปรด** — บันทึกการตรวจสอบที่ผ่านมา; ปักหมุดผู้ขายสำคัญด้วย ⭐ เพื่อไม่ให้ถูกลบทิ้งอัตโนมัติ
- **เข้าสู่ระบบด้วย Google คลิกเดียว** — ไม่ต้องสมัครสมาชิก

## วิธีติดตั้ง (Chrome)

> ส่วนขยายอยู่ระหว่างพัฒนา จึงต้องติดตั้งด้วยตนเองผ่าน "โหมดนักพัฒนา" ทำตาม 4 ขั้นตอนนี้:

### ขั้นตอนที่ 1 — ดาวน์โหลด

ดาวน์โหลดและแตกไฟล์ zip เวอร์ชันล่าสุดจากหน้า **Releases** ของ repo นี้

### ขั้นตอนที่ 2 — เปิดหน้าการจัดการส่วนขยาย

พิมพ์ `chrome://extensions` ในแถบที่อยู่ แล้วกด **Enter**

### ขั้นตอนที่ 3 — เปิดโหมดนักพัฒนา

สลับเปิด **Developer mode** (มุมขวาบนของหน้า)

### ขั้นตอนที่ 4 — โหลดส่วนขยาย

1. คลิก **Load unpacked**
2. เลือก **โฟลเดอร์ที่แตกไฟล์แล้ว** (โฟลเดอร์ที่มีไฟล์ `manifest.json`)
3. ไอคอน Sourcely จะปรากฏบนแถบเครื่องมือของเบราว์เซอร์ — สามารถปักหมุดได้

## วิธีใช้งาน

1. ไปที่หน้ารายการสินค้าบน `1688.com`
2. คลิกไอคอน **Sourcely** บนแถบเครื่องมือ
3. อ่านรายงานผู้ขาย — คะแนน, ผลสรุป และการเปรียบเทียบ
4. เข้าสู่ระบบด้วย Google เมื่อระบบแจ้ง

## คำถามที่พบบ่อย

**ทำไมต้องใช้โหมดนักพัฒนา?**
เพราะส่วนขยายยังไม่ได้เผยแพร่บน Chrome Web Store เมื่อได้รับการอนุมัติแล้วจะติดตั้งด้วยคลิกเดียว — ไม่ต้องใช้โหมดนักพัฒนา

**มีค่าใช้จ่ายหรือไม่?**
บริการมีโควตาฟรีสำหรับใช้รายวัน และแผนชำระเงินที่ให้โควตาสูงกว่า รายละเอียดแสดงในส่วนขยายหลังเข้าสู่ระบบ

**มีปัญหาหรือต้องการให้คำแนะนำ?**
เปิด issue ใน repo นี้ หรือติดต่อผ่านลิงก์สนับสนุนในส่วนขยาย
